# 에이전트 전용 머신 상시 설정

- 요청일: 2026-08-19
- 요청자 지시 원문: "이 컴퓨터는 오직 ai에이전트를 위한 컴퓨터야",
  "모든 작업 및 의사결정을 가장 공격적으로 할거야"

## 목표

이 PC 를 에이전트 전용으로 상시 대기 상태로 만든다. 위임 초인종을 놓치지 않고,
매번 승인 프롬프트를 받지 않도록 한다.

## 실행 절차

`docs/AGENT_POLICY.md` 의 "전용 머신 설정 체크리스트" 를 실제로 적용한다.

1. **절전·최대 절전·화면보호기 끄기** — 절전되면 트리거가 도달하지 않는다
   (Windows: 전원 옵션에서 절전/디스플레이 끄기를 "안 함"으로)
2. **`claude remote-control` 부팅 시 자동 실행** — 작업 스케줄러에 로그온 트리거로 등록.
   작업 디렉터리는 이 저장소 경로로 한다
3. **권한 모드 상시 허용** — `~/.claude/settings.json` 의 permission mode 를
   `bypassPermissions` (또는 `dontAsk`) 로 설정
4. **Remote Control 자동 연결** — 모든 세션에서 켜지도록 설정
5. **`~/.claude/CLAUDE.md`** 작성 — 아래 내용을 넣어 모든 로컬 세션이 방침을 따르게 한다:
   - 이 PC 는 AI 에이전트 전용 머신이다. 로컬 실행은 승인 없이 공격적으로 진행한다
   - 위임받은 작업은 결과를 해당 저장소 `handoff/results/` 에 기록하고 커밋·푸시한다.
     실패해도 반드시 남긴다
   - 확인이 필요한 것은 계정·결제 변경, 영구 삭제, 자격 증명뿐이다
   - 보고 정확성은 자율성과 별개다. 확인하지 않은 것을 확인했다고 하지 않는다
6. **`handoff/inbox/` 정기 스윕** — 초인종을 놓쳤을 때를 대비해 미처리 작업서를
   주기적으로 확인하는 Routine 을 건다 (1시간 간격 권장).
   미처리 = `inbox/` 에 있고 같은 이름의 `results/` 파일이 없는 것
7. 디스크 여유 확인 — 영상 렌더 산출물이 쌓인다

## 검증

- [ ] PC 를 잠시 방치해도 절전되지 않는지
- [ ] 재부팅 후 `claude remote-control` 이 자동으로 떠 있는지
- [ ] 승인 프롬프트 없이 파일 수정·명령 실행이 되는지
- [ ] 스윕 Routine 이 등록되어 다음 실행 시각이 잡혀 있는지

## 하지 말 것

- 사용자 데이터 삭제나 기존 스케줄 작업 제거
- 방화벽·보안 소프트웨어를 끄는 방식의 우회

## 사용자 승인이 필요한 지점

권한 모드를 `bypassPermissions` 로 바꾸는 것은 사용자가 이미 지시했다 (전용 머신 방침).
그 외 시스템 설정 변경은 되돌릴 수 있으므로 진행한다.
