# 작업 위임 통로

- `inbox/` — 클라우드 세션이 쓰는 작업서. PC 세션이 처리한다.
- `results/` — PC 세션이 쓰는 결과. 클라우드 세션이 `git fetch` 로 읽는다.

`inbox/` 에 있고 같은 이름의 `results/` 파일이 없으면 **미처리 작업**이다.
PC 가 꺼져 있어 초인종(트리거)이 도달하지 않았어도 작업서는 남으므로,
나중에 켜서 `git pull` 하면 밀린 작업을 찾을 수 있다.

실패해도 반드시 `results/` 에 남긴다. 조용히 끝내면 진행 중인지 실패인지 구분할 수 없다.

형식과 규칙: `docs/DISPATCH.md`
