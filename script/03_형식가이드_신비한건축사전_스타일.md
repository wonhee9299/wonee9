# 형식 가이드 — "신비한 건축사전" 스타일로 만들기

참고 영상: https://youtu.be/35lHzyVx_qM ("콘크리트를 21cm나 깔았는데 층간소음이 그대로인 이유", 채널 신비한 건축사전)

## 1. 참고 채널의 형식 분석 (공개 정보 기준)

| 요소 | 참고 채널 | 우리 영상에 적용 |
|---|---|---|
| 구조 | **도입(질문 훅) → 난관(왜 안 되는가) → 해결(원리) → 요약** 4파트 | 그대로 채택. 한 편에 질문 하나 |
| 화면 | AI 생성 영상(VEO 계열) 사실적 3D 장면, **흰색·회색 저채도 배경 + 붉은색 고대비 강조**, 픽토그램, 단순화한 그래프 | 배경·픽토그램은 동일 팔레트. 차트는 기존 7장을 흰 배경·붉은 강조로 재도색 |
| 나레이션 | TTS 남성, 차분하고 단정적인 문장. "~입니다", "~겁니다" | edge-tts ko-KR-InJoonNeural (작동 확인됨) |
| 자막 | 화면 하단 큰 흰색 굵은 글씨 + 검은 외곽선, 핵심 단어만 붉은색 | 동일. Noto Sans KR Black |
| 숫자 | **수치 설명을 최대한 피하고 상식 수준으로** | ⚠ 충돌 지점. 아래 §3 참고 |
| 길이 | 짧은 단일 질문형 (수 분 단위) | 한 편 6~8분 목표, 3부작 |
| 썸네일 | 좌우 2분할, 한 화면에 큰 문장 두 줄("21cm인데 / 왜 들릴까?"), 붉은 강조 | "60조 벌었는데 / 왜 떨어졌을까?" |
| 컷 길이 | 컷당 4~8초, 장면마다 화면 전환 | 컷당 5~8초, 편당 60~80컷 |

## 2. 우리 환경에서 만들 수 있는 것 / 없는 것

**만들 수 있는 것 (이 저장소에서 바로)**
- 컷 단위 대본 + 컷별 AI 영상 프롬프트 (VEO / Sora / Runway 용, 영어)
- 나레이션 오디오 (edge-tts, 한국어 남성) + 컷별 타이밍 + SRT 자막
- 차트·픽토그램 컷 (Python/HTML 렌더, 흰 배경·붉은 강조로 통일)
- 썸네일 (HTML → PNG)
- 조립 스크립트 (ffmpeg): 컷 영상/이미지 + 나레이션 + 자막 → mp4

**만들 수 없는 것 (사용자가 외부 도구로)**
- AI 생성 실사풍 영상 클립 (VEO 등). 이 환경에는 영상 생성 모델 접근이 없음
- 대안 A: 사용자가 프롬프트로 클립 생성 → `clips/` 폴더에 넣으면 조립 스크립트가 합침
- 대안 B: AI 클립 없이 픽토그램·차트·정지 이미지에 줌/패닝(켄번즈) 효과로 전편 제작. 참고 채널보다 단순하지만 전 과정 자동화 가능

## 3. 충돌 지점: "숫자를 피하는 채널" vs "재무제표 교육 영상"

참고 채널의 정체성은 "수치 대신 상식 수준 설명"입니다. 우리 대본은 재무제표가 주제라 숫자가 본체입니다. 그대로 옮기면 채널 형식도, 교육 목적도 둘 다 어긋납니다.

절충안:
1. **한 컷에 숫자 하나.** 표는 쓰지 않고, 화면에 큰 숫자 한 개와 픽토그램 하나만 둔다. (예: 이익잉여금 242조 → 동전 더미 픽토그램 + "242조" 한 줄)
2. **숫자를 비유로 번역한다.** "부채비율 87%" 대신 "빚이 내 돈의 0.9배" / "잉여현금 −5조" 대신 "번 돈보다 공장에 쓴 돈이 많았던 해"
3. **차트는 편당 최대 2장**, 나머지는 픽토그램·장면으로 대체.
4. 정확한 수치는 **더보기 설명란과 저장소 문서**에 두고 영상에서는 반올림한 숫자만.

## 4. 3부작 구성 제안 (편당 6~8분)

| 편 | 제목(썸네일 문장) | 질문 | 도입 / 난관 / 해결 / 요약 |
|---|---|---|---|
| 1 | **60조 벌었는데 / 왜 떨어졌을까?** | 역대 최대 실적인데 주가가 빠진 이유 | 도입: 7/29 −9.6% · 난관: 재무제표는 과거다 · 해결: 장부·현금·기대 세 렌즈, 주가는 이익보다 먼저 움직인다(차트 06) · 요약: 숫자가 아니라 기대와의 차이 |
| 2 | **같은 D램인데 / 왜 하이닉스만 벌까?** | 이익률 76%의 정체 | 도입: 100원 팔면 76원 남는 장사 · 난관: 원래 사이클 산업이었다 · 해결: HBM, 셋뿐인 공급자, 5년 계약 · 요약: 부품에서 맞춤형으로 |
| 3 | **주가 292만 → 132만 / 앞으로는?** | 이익은 느는데 주가는 왜 흔들리나 | 도입: 6월 고점 후 −55% · 난관: 이미 반영된 기대 · 해결: 추정치를 올리는 것 3개 / 내리는 것 4개 · 요약: 지켜볼 4가지 |

기존 16분 대본(`01_대본`)은 자료집으로 유지하고, 3부작 컷 대본은 `04_컷대본_1편.md` 부터 새로 작성.

## 5. 제작 파이프라인 (저장소 기준)

```
script/04_컷대본_1편.md        컷 번호 / 나레이션 / 화면 / AI 프롬프트 / 자막 강조어
   │
   ├─ scripts/build_narration.py   → audio/ep1/cut_01.mp3 ... + timing.json + ep1.srt   (edge-tts)
   ├─ scripts/make_charts*.py      → charts/light/*.png  (흰 배경·붉은 강조 버전)
   ├─ scripts/make_cards.py        → cards/ep1/cut_XX.png  (픽토그램·큰 숫자·자막 카드, HTML→PNG)
   ├─ clips/ep1/cut_XX.mp4         ← 사용자가 VEO 등으로 생성 (없으면 cards로 대체)
   └─ scripts/assemble.py          → output/ep1.mp4  (ffmpeg: 컷 이어붙이기 + 오디오 + 자막 번인)
```

컷마다 `clips/`에 영상이 있으면 그것을, 없으면 `cards/`의 이미지를 켄번즈 효과로 씁니다. 그래서 AI 클립이 0개여도 완성본이 나오고, 클립을 채울수록 참고 채널에 가까워집니다.

## 6. 화면 팔레트 (참고 채널 톤)

- 배경: `#f4f4f2` (거의 흰색) / 보조 회색 `#c9c9c6`
- 본문 텍스트: `#1a1a19`
- 강조(붉은색): `#e03a2f` — 한 화면에 한 곳만
- 하락·위험: 같은 붉은색 / 상승·긍정: 검정 굵은 글씨 (참고 채널은 초록·파랑을 거의 쓰지 않음)
- 자막: 흰색 Noto Sans KR Black 64px, 검은 외곽선 6px, 강조어만 `#e03a2f`
- 차트: 선·막대는 `#3a3a38` 회색, 핵심 막대/구간만 붉은색

## 7. AI 영상 프롬프트 작성 규칙 (VEO/Sora 용)

- 영어, 한 문장 30단어 내외, 카메라 움직임 1개, 피사체 1개, 색 지시 고정: `monochrome white-grey environment, single red accent, soft studio light, photorealistic 3D render, slow camera push-in, no text, no people's faces`
- 8초 클립 기준, 16:9, 사람 얼굴·로고·실제 회사 건물은 넣지 않음(초상권·상표)
- 숫자·글자는 영상에 넣지 않고 자막 레이어로 얹음 (AI 생성 텍스트는 깨짐)
