# 컷 대본 1편 — "60조 벌었는데 왜 떨어졌을까?"

- 형식: 신비한 건축사전 스타일 (도입 → 난관 → 해결 → 요약), 목표 길이 6~7분, 53컷
- 나레이션: edge-tts `ko-KR-InJoonNeural`, 컷당 1~2문장
- 화면 규칙: 흰색·회색 저채도 배경, 붉은 강조는 한 화면에 한 곳, 숫자는 한 컷에 하나
- 프롬프트 공통 접미어(모든 AI 클립에 붙임): `monochrome white and grey environment, one red accent element, soft studio light, photorealistic 3D render, 16:9, no text, no faces, no logos`
- 각 컷: **나** = 나레이션 / **화** = 화면 지시(카드 대체 가능) / **P** = AI 영상 프롬프트(영어) / **강** = 자막 붉은 강조어
- 클립이 없는 컷은 `cards/`의 카드 이미지(픽토그램 + 큰 숫자 + 자막)로 자동 대체
