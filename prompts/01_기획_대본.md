# 1단계: 주제 → 대본 + 장면표 만들기

아래 프롬프트를 Codex, ChatGPT, Claude 중 아무 데나 통째로 붙여넣으세요.
`[주제]`만 바꾸면 됩니다. 결과로 나오는 JSON을 `project/scenes.json`으로 저장하면
`pipeline/make_video.py`가 그대로 읽습니다.

---

```
당신은 조회수가 잘 나오는 "공학·건축 설명 영상"의 작가입니다.
시청자는 전문 지식이 없는 일반인입니다. 어려운 용어는 한 문장으로 풀어 설명합니다.

[주제]: 용인 도심 인공호수가 빗물을 땅속으로 침투시켜 홍수를 막는 원리

요구사항
1. 총 길이 60~90초, 장면(scene) 8~12개.
2. 첫 장면은 3초 안에 궁금증을 만드는 훅(hook)으로 시작합니다.
   예: "이 호수는 사실 물을 담기 위한 게 아닙니다."
3. 각 장면의 나레이션은 1~2문장, 25~45자, 구어체 "~합니다" 체.
4. 각 장면마다 구체적인 숫자(치수, 용량, 시간, 비율)를 최소 1개 넣습니다.
   실제 수치를 모르면 현실적인 추정치를 쓰고 scene의 "note"에 "추정"이라고 적습니다.
5. 각 장면에 대해 다음을 함께 작성합니다.
   - subtitle: 화면 하단 자막용 짧은 문구 (15자 이내, 핵심 숫자 포함)
   - image_prompt: 인포그래픽 이미지 생성용 영문 프롬프트. 아래 스타일 규칙을 반드시 지킵니다.
   - motion_prompt: 이미지를 영상으로 만들 때 쓸 카메라/애니메이션 지시 (영문, 1문장)

image_prompt 스타일 규칙 (모든 장면에 공통 적용)
- 3D isometric cutaway (단면) view, clean gray low-poly city buildings, soft studio lighting
- 지형은 층별로 색을 다르게 (top soil: sand color, gravel: gray, bedrock: dark)
- 물의 흐름은 glowing cyan arrows 로 표현
- 치수선(dimension lines)과 라벨을 흰색 얇은 선 + 흰색 글씨로 표시, 라벨 텍스트는 영문 또는 숫자만
- 배경은 어두운 회색, 화면 하단 25%는 자막을 위해 비워둠
- 실사 사람, 회사 로고, 워터마크 금지

출력 형식: 아래 JSON만 출력합니다. 설명 문장을 붙이지 마세요.
{
  "title": "영상 제목 (30자 이내, 숫자 포함)",
  "hook_thumbnail_text": "썸네일용 2줄 문구",
  "voice": "ko-KR-InJoonNeural",
  "scenes": [
    {
      "id": 1,
      "narration": "...",
      "subtitle": "...",
      "image_prompt": "...",
      "motion_prompt": "...",
      "note": ""
    }
  ]
}
```

---

## 팁

- 결과가 마음에 안 들면 "장면 3의 숫자를 더 구체적으로", "훅을 3개 더 제안해줘"처럼 부분만 다시 시킵니다.
- 같은 대화에서 "이 구조 그대로 주제만 `○○`으로 바꿔서 다시 만들어줘"라고 하면 시리즈 제작이 빨라집니다.
- 수치는 반드시 사람이 한 번 검증하세요. AI가 만든 숫자는 틀릴 수 있고, 틀린 숫자는 댓글에서 바로 지적당합니다.
