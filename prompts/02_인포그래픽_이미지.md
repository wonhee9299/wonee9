# 2단계: 장면별 인포그래픽 이미지 만들기

1단계 JSON의 각 `image_prompt`를 이미지 생성 도구에 넣습니다.
쓸 수 있는 도구 (아무거나 하나):

| 도구 | 비용 | 비고 |
|---|---|---|
| Google Flow (Imagen) | Google AI Pro 구독 | 원본 영상이 쓴 도구. 3단계 영상화와 같은 곳에서 처리 가능 |
| Gemini 앱 이미지 생성 | 무료 한도 있음 | 텍스트 라벨 정확도가 높은 편 |
| ChatGPT 이미지 생성 | Plus 구독 | 치수선·라벨 표현이 안정적 |

## 공통 접두어 (모든 image_prompt 앞에 붙이기)

```
16:9 aspect ratio, 3D isometric cutaway infographic, clean gray low-poly city,
soft studio lighting, dark gray background, thin white dimension lines with white labels,
glowing cyan arrows showing water flow, layered soil cross-section
(sand-colored top soil, gray gravel, dark bedrock), bottom 25% of frame left empty,
no people, no logos, no watermark, no Korean text.
```

## 예시 (장면 1: 훅)

```
16:9 aspect ratio, 3D isometric cutaway infographic, ... (위 접두어) ...
Scene: an artificial lake in the middle of a dense gray city block, 150 m wide,
seen from a high angle. Below the lake a cutaway reveals a 2.5 m top soil layer
with dozens of small holes, cyan arrows pointing downward into the ground.
Dimension line across the lake labeled "150 m", vertical line labeled "2.5 m".
```

## 라벨 텍스트가 깨질 때

- 라벨은 영문·숫자만 쓰세요. 한글은 대부분의 이미지 모델에서 깨집니다.
- 그래도 깨지면 이미지에서 라벨을 빼고(`no text labels`), 자막이나 편집 단계에서 글자를 얹습니다.
- 한 장면당 3~4장 뽑아서 가장 깨끗한 것을 고르세요. 10장 중 8~9장은 쓸 만하다는 후기가 있지만, 라벨이 있는 장면은 실패율이 더 높습니다.

## 파일 저장 규칙

`project/media/` 폴더에 장면 번호 두 자리로 저장합니다.

```
project/media/01.png
project/media/02.png
...
```

이 규칙을 지키면 `make_video.py`가 자동으로 찾습니다.
