# 인물 서사 — 캐릭터 우선 접근

전체 세계관보다 **인물 서사를 먼저 구축**한다. 근거:

- 『삼국지연의』의 실질적 흥행 엔진은 국가 흥망이 아니라 조조·제갈량·관우 같은 **인물의 아크**였다.
  코에이 게임도, 웹툰도, 드라마 캐스팅도 결국 인물 단위로 팔린다.
- 인물 서사가 먼저 서면 세계관(연표·사건)은 인물들의 교차점으로 자연스럽게 조립된다.

## 서사 템플릿 (각 인물 문서 공통 구조)

1. **아키타입 매칭** — 어떤 연의 인물의 서사 기능에 대응하는가, 어디가 같고 어디가 다른가
2. **정사의 뼈대(七實)** — 『삼국사기』 등 기록 사실. 이 선은 창작이 넘지 않는다
3. **설화·소재(利庫)** — 『삼국유사』·구비설화·『일본서기』 등에서 가져올 수 있는 극적 재료
4. **인물 해석** — 욕망 / 결핍 / 모순 (캐릭터의 내적 엔진)
5. **3막 서사 아크** — 창작 구간은 `[虛]` 표기로 사실과 구분
6. **명장면 후보** — 연의의 "삼고초려·단기천리"에 해당하는 상품화 가능한 장면들
7. **관계망** — 다른 인물 서사와의 교차점 (세계관 조립용 훅)
8. **상품화 노트** — 캐릭터 IP로서의 포지션
