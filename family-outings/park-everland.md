## 0. 먼저 — 제가 앞서 한 조언을 정정합니다

바이블에서 **"C시즌 평일 + 카드 50% = 4인 8만원대"**라고 했는데, 이건 **지금 시기엔 성립하지 않습니다.**

> **9월~11월 초에는 B·C시즌이 아예 없습니다.** 이 기간 평일은 전부 **A시즌**입니다.

따라서 **9~10월 평일에 가면 A시즌 정가 228,000원**이 출발점입니다. 8만원대는 **3월 중순 이전이나 겨울 비수기**에나 가능한 숫자였습니다.

**그래도 평일은 맞는 선택입니다.** 이유는 요금이 아니라 **대기시간**이기 때문입니다 — 아래 3번 참조.

| 언제 가느냐 | 시즌 | 4인 정가 |
|---|---|---|
| **9월~11월 초 평일** (지금) | **A** | **228,000** |
| 11월 중순~1월 초 평일 | A 또는 B (확인 필요) | 188,000~228,000 |
| 1월 중순~3월 중순 평일 | **B·C 존재** | 164,000~188,000 |
| 3월 20일~6월 초 | A | 228,000 |

**정확한 시즌은 에버랜드 앱 → 전체메뉴 → 이용요금 → 시즌 캘린더보기**에서 날짜별로 확인하세요. 이게 D-7 첫 번째 할 일입니다.

## 1. 요금 — 할인이 전부

### 시즌별 정가
| 시즌 | 대인(성인·청소년) | 소인(36개월~12세) | 4인 정가 |
|---|---|---|---|
| C (비수기 평일) | 46,000 | 36,000 | 164,000 |
| B | 52,000 | 42,000 | 188,000 |
| **A (지금 평일)** | **62,000** | **52,000** | **228,000** |
| D (극성수기) | 68,000 | 58,000 | 252,000 |

우리 가족 = 대인 2 + 소인 2 (둘째는 36개월 이상이라 유료)

### 할인 경로 — D-7에 전부 비교할 것
| 경로 | 할인율 | 비고 |
|---|---|---|
| **카드사 제휴** | 최대 50% | 삼성·신한·KB국민·현대. 본인+동반 인원 제한 확인 |
| KT 멤버십 | 30% (VVIP 50%) | |
| LG U+ | 30~40% | |
| 온라인 플랫폼 | 변동 | 네이버예약·야놀자·클룩 선착순 쿠폰 |

**A시즌 228,000원에 카드 50%를 적용하면 약 114,000원.** 서울랜드(8만원)보다는 비싸지만, T익스프레스 값으로는 납득할 만합니다.

### 오후권 — 검토할 만한 카드
- **15시 이후 29,000원** / 16시 이후 36,000원

4인 오후권(15시)이면 **116,000원**인데 종일권 할인가와 비슷합니다. 다만 **평일 오픈런의 이점을 버리게 되므로 이번엔 종일권**을 권합니다. 오후권은 "둘째가 낮잠을 못 건너뛰는 시기"에 다시 검토하세요.

## 2. 주차 — 무료 주차장이 있습니다

| 구분 | 요금 |
|---|---|
| **1·2·3번 주차장** | **무료** (정문까지 셔틀 5분 간격) |
| 정문 주차장 | 일 최대 15,000원 |
| 카카오T 모바일 정산 | 최대 5,000원 할인 |

**평일이면 정문 유료주차장도 널널하다**는 실제 후기가 있습니다(8시 40분 도착 시 F라인 여유). 다만 **1~3번 무료 주차장 + 셔틀**이면 15,000원이 0원이 됩니다.

> **판단**: 유모차와 짐이 있으니 **첫 방문은 정문 유료(카카오T 할인 적용 10,000원)**, 익숙해지면 무료 주차장. 15,000원을 아끼려다 3세를 셔틀에 태우는 게 나은지는 당일 컨디션으로 판단하세요.

## 3. 평일이 옳은 진짜 이유 — 실측 대기시간

평일 5월 오픈런 방문기의 실제 기록입니다.

| 시각 | 상황 |
|---|---|
| 08:40 | 정문 유료주차장 도착 — **널널했음** |
| 09:00~09:55 | 게이트 대기. 입장 줄 10개 이상 운영 |
| **09:55** | **개장 5분 전 입장 시작** |
| 입장 직후 | **로스트밸리 대기 0분** |
| 이어서 | 사파리월드 약 20분 |
| 이어서 | 판다월드 약 10분 |
| **오후** | **회전목마·피터팬·붕붕카 등 유아 기구 거의 대기 없이 연속 탑승** |

### 서울랜드와 정반대입니다 — 법칙 3의 예외

서울랜드에서는 **유소아 기구가 더 붐볐는데**, 에버랜드 평일에는 **오후 유아 기구가 거의 대기 없음**입니다.

파크 규모 차이로 보입니다. 에버랜드는 유아 기구가 여러 존에 분산돼 있고 전체 면적이 커서 수요가 몰리지 않습니다.

> **전략 수정**: 서울랜드처럼 "둘째 팀도 오픈런"할 필요가 없습니다. **오전은 첫째 코스터에 집중하고, 둘째는 오후에 몰아서** 타는 게 평일 에버랜드에는 맞습니다.

## 5. 오늘의 승부처 — T익스프레스를 어떻게 탈 것인가

첫째의 이번 방문 최대 목표이고, 대기가 가장 긴 기구입니다.

### 선택지 3개

| 방법 | 비용 | 판단 |
|---|---|---|
| **오픈런 직행** | 0원 | 평일이면 승산 있음. 단 로스트밸리·사파리와 택일 |
| **큐패스 구매** | 15,000원 | 1~2시간을 사는 셈 |
| **앱으로 대기 감시** | 0원 | 30분 이하로 떨어질 때 이동. 실제 성공 사례 있음 |

> **권장**: **오픈런으로 T익스프레스 직행**하고, 실패하면 **앱으로 대기시간을 보다가 30분 이하일 때 재도전**합니다. 큐패스 15,000원은 오전이 완전히 망했을 때의 보험으로 남겨두세요.
>
> 오픈런 후기에서는 **"사파리월드 또는 로스트밸리 한 곳을 타겟으로 직진"**을 권합니다. 우리는 **T익스프레스가 타겟**입니다 — 목표가 다르면 동선도 달라야 합니다.

### 큐패스 가격 (2025년 기준, 재확인 필요)
T익스프레스 15,000 / 사파리월드 10,000 / 로스트밸리 9,000 / 판다월드 7,000. 패키지 2~4만원.

## 6. 도시락이 막힙니다 — 이 파크의 최대 약점

**에버랜드는 도시락 반입이 제한됩니다.** 물과 간단한 간식(과자·빵·젤리)은 되지만 도시락은 안 됩니다.

### 실전 대응 (평일 방문기에서 나온 방법)
> **전날 김밥을 사두고, 입장 전에 아이들에게 먹였다.**

이게 현실적인 답입니다. 순서는 이렇습니다.

| 시점 | 방법 |
|---|---|
| 08:40~09:30 | **주차장·게이트 대기 중 차 안에서 김밥** — 반입이 아니라 입장 전 취식 |
| 파크 안 | 물·과자·젤리로 버티기 (반입 가능) |
| 늦은 점심 | 푸드코트 or 재입장 후 외부 |
| 저녁 | 귀가 후 집에서 |

**게이트에서 1시간 대기하는 시간이 아침 겸 점심을 먹는 시간이 됩니다.** 오픈런의 부수 효과입니다.

### 비용 시나리오
| 점심 방식 | 4인 추가 |
|---|---|
| 입장 전 김밥 + 간식 반입 + 늦은 간단 식사 | 약 20,000~30,000 |
| 파크 내 푸드코트 정식 | 60,000~80,000 (추정) |
| 재입장 후 외부 식사 | 30,000~40,000 (**재입장 가능 여부 확인 필요**) |

### 파크 안 편의점 — 도시락이 막히면 여기가 대안

| 위치 | 매장 |
|---|---|
| 정문 매표소 옆 (파크 밖) | GS25 |
| 셔틀버스 탑승장 뒤 (파크 밖) | CU |
| 글로벌페어 — 정문 통과 후 메인 스트리트 | CU |
| 아메리칸 어드벤처 — 버거카페 아메리카 근처 | CU |
| 유러피언 어드벤처 — 홀랜드 빌리지 안쪽 | CU |

**유러피언 어드벤처가 레스토랑이 가장 많은 구역**이다. 늦은 점심은 여기로 온다.

### 유아휴게실 4곳

**스카이크루즈 베이비 · 알파인 베이비 · 포시즌스 베이비 · 이솝 베이비.** 수유·기저귀 교환 가능.
**전자레인지 유무는 미확인** — D-1 전화 항목에 넣었다. 서울랜드에는 수유실에 전자레인지가 있었다.

### 존 구성 (개략도 기준)

| 존 | 우리 가족에게 |
|---|---|
| 글로벌페어 (정문) | 안내센터 · 유모차/웨건 대여 · 수유실. **흩어지면 여기서 만난다** |
| 유러피언 어드벤처 | **T익스프레스.** 레스토랑 최다. 포시즌스 가든 그늘·벤치 |
| 주토피아 | 로스트밸리·사파리월드·판다월드. **셋 다 앉아서 이동** — 3세에게 최적 |
