# 에버랜드 가족 나들이 계획서

아빠 + 엄마 + 첫째 8세(130cm) + 둘째 3세 후반(101cm) / 경기 용인 / 하남에서 차로 약 1시간

> [마스터 바이블](./theme-park-bible.md)의 5가지 법칙을 적용한 계획서. 방문일이 정해지면 이 문서를 복사해 `YYYY-MM-DD-everland.md`로 만든다.

## 이 파크의 한 줄 결론

**첫째가 T익스프레스(130cm)를 탈 수 있는 첫 파크.** 서울랜드에서 140cm에 막혔던 아쉬움을 여기서 푼다. 대신 **도시락 반입이 제한**되고 정가가 비싸서, 티켓 할인과 식사 전략이 승부처다.

## 1. 요금 — 시즌에 따라 4인 8만원 차이

| 시즌 | 대인(성인·청소년) | 소인(36개월~12세) | 4인 정가 |
|---|---|---|---|
| C (평일 최저) | 46,000 | 36,000 | **164,000** |
| B (비수기 평일) | 52,000 | 42,000 | 188,000 |
| A (일반 평일·주말) | 62,000 | 52,000 | 228,000 |
| D (극성수기·공휴일) | 68,000 | 58,000 | **252,000** |

**우리 가족 계산**: 어른 2 + 첫째(소인) + 둘째(소인, 36개월 이상이라 유료) = 대인 2 + 소인 2

**오후권**: 15시 이후 29,000 / 16시 이후 36,000

### 할인 경로 (반드시 쓸 것)
- **카드사 제휴**: 삼성·신한·KB국민·현대 등 **최대 50%**
- **통신사**: KT 30% (VVIP 50%), LG U+ 30~40%
- **온라인 플랫폼**: 네이버예약·야놀자·클룩 선착순 쿠폰, 콤보 패키지

> **C시즌 평일 + 카드 50% 할인**이면 4인 8만원대까지 내려간다. 서울랜드 수준이 된다.
> **D시즌 주말 정가**로 가면 25만원. **날짜 선택이 이 파크 가성비의 전부다.**

## 3. 우선탑승권 — 전액 유료 (법칙 1)

에버랜드 큐패스는 **무료가 아니다.** 단품 가격(2025년 기준):

| 대상 | 가격 |
|---|---|
| T 익스프레스 | 15,000 |
| 사파리월드 | 10,000 |
| 로스트밸리 | 9,000 |
| 판다월드 | 7,000 |

패키지형은 2~4만원 선. **자유이용권과 별도 지출**이다.

> **판단**: 가성비 원칙상 기본은 안 산다. 다만 **T익스프레스 하나만은 예외를 검토**할 만하다 — 첫째의 이번 방문 최대 목표이고, 대기가 길기로 유명하다. 15,000원으로 1~2시간을 사는 셈.
> **D-1 전화로 현재 가격·정책 재확인 필수.**

## 4. 조사 못 한 것 (D-1에 반드시 확인)

에버랜드 공식 사이트가 접속을 막아 다음을 확인하지 못했다:

- [ ] **주차요금** (검색으로도 안 나옴)
- [ ] **공연 시간표·예약 방법** (법칙 2)
- [ ] **외부 음식 정확한 규정** — "물·간단한 간식은 되고 도시락은 제한"이라는 2차 정보만 확보. 유아 이유식 예외가 있는지 확인
- [ ] 물놀이 시설 / 돗자리 가능 구역 (법칙 4)
- [ ] 유아휴게실 전자레인지 유무
- [ ] 재입장 가능 여부 — 가능하면 **정문 밖에서 점심 먹고 재입장**이 최대 절감 카드

**전화**: 에버랜드 고객센터 (공식 사이트에서 확인)

## 4-2. 여름 시즌이라면 — 워터팡팡 어드벤처 (법칙 4)

에버랜드 여름 시즌에는 **약 830㎡ 규모 복합 물놀이존 '워터팡팡 어드벤처'**가 운영된다. 워터 카니발 게임, 워터캐논, 댄스 공연이 있고, 어린이 참여형 **'밤밤맨 키즈 워터파티'** 공연도 열린다.

**둘째(3세)에게 이번 여름 최고의 코스가 될 수 있다.** 코스터를 못 타는 나이에 물놀이는 나이 제한이 없다.

- 여름 방문이면 **여벌옷·수건·아쿠아슈즈**를 반드시 챙길 것
- '썸머 워터 펀' 워터 페스티벌 퍼레이드, 나이트 사파리, 반딧불이 체험도 여름 한정
- **캐리비안베이는 별도 파크·별도 요금** — 투파크 무료입장 프로모션이 있는 해도 있으니 확인

## 5. 식사 전략 — 도시락이 막히는 경우

| 방법 | 예상 | 비고 |
|---|---|---|
| 재입장 후 외부 식사 | 4인 3~4만원 | **재입장 가능 여부 확인 필수** |
| 파크 내 푸드코트 | 4인 6~8만원 추정 | 확인 필요 |
| 물 + 간식만 반입 + 간단히 | 4인 3만원대 | 허용 범위 내에서 최대한 |

**물과 간단한 간식(과자·젤리·빵)은 반입 가능**하므로, 아침을 든든히 먹고 간식으로 버티다 늦은 점심을 파크 밖에서 해결하는 것이 가성비 최선일 수 있다.
