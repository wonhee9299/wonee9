## 운영 원칙

- **출처 등급을 붙인다.** A=공식 확인 / B=2차 자료 교차확인 / C=1회 관찰(표본 1 명시) / D=미확인.
  **C는 일반 가이드 본문에 넣지 않는다.** 1회 관찰을 법칙으로 승격시키지 않는다.
- **"확인 필요"는 정말 확인 불가능할 때만 쓴다.** 조사하면 알 수 있는 것을 독자에게 떠넘기지 않는다.
- **반례가 나오면 법칙을 버린다.** 조건을 덧붙여 살리지 않는다.

- **성공 기준은 많이 보기보다 정확히 쓰고 나오는 것.** 장소를 욱여넣지 않는다. 지치기 전에 끝낸다.
- **정보는 반드시 검증한다.** 운영시간·요금·연령 제한은 공식 홈페이지나 최근 방문 후기로 교차 확인하고, 출처 링크를 남긴다. 확실하지 않은 건 "현장 확인 필요"라고 표시하지 추측해서 채우지 않는다.
- **전화 확인이 필요한 항목은 체크리스트에 반드시 넣는다.** (연령 제한, 예약 필요 여부, 휴무일 등)
- **비용은 항목별로 쪼개서 총액을 미리 예상한다.** 놀라는 지출이 없어야 "가성비"다.
- **예약제는 어트랙션·공연을 따로 확인한다.** 무료인지 유료인지, 예약 오픈이 언제인지까지. 블로그·뉴스 정보는 1년만 지나도 무효이므로 방문 1~2일 전 전화로 확정한다.
- **물놀이 시설과 돗자리 가능 구역은 따로 확인한다.** 준비물과 휴식 거점이 통째로 바뀐다.
- **아이 인원·나이가 바뀌면 코스도 바뀐다.** 매번 참가자 구성을 기록해서 나중에 비교할 수 있게 한다.

## 새 가이드 만드는 법

1. `TEMPLATE.md`를 복사해 `family-outings/YYYY-MM-DD-지역명.md`로 저장
2. 장소별 운영시간·요금·연령 제한을 실제 출처(공식 사이트, 최근 후기)로 확인하며 채움
3. 스케줄·동선·비용·체크리스트까지 다 채우면 위 목록 표에 한 줄 추가
4. 방문 후 실제로 달랐던 점이 있으면 "방문 후 메모" 섹션에 남겨서 다음 계획에 반영
