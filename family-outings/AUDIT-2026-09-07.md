# 바이블·가이드 감사 — 2026-09-07

공유용 가이드에 대한 세 가지 지적을 검증하고, 재조사 과정에서 추가로 발견한 오류까지 모은 문서.
**이 감사를 끝내기 전에는 가이드를 다시 쓰지 않는다.**

## 지적 1 — 일반 가이드에 개인 경험이 섞여 있다

**타당하다.** "일반화했다"고 썼지만 실제로는 서사만 3인칭으로 바꾸고 내용은 우리 집 하루 그대로였다.

### 어디가 개인 경험인가

| 위치 | 내용 | 왜 문제인가 |
|---|---|---|
| 1장 함정 5가지 | 전부 1인칭 일화 ("갔는데", "못 봤습니다", "빗나갔습니다") | **n=1 경험을 모든 방문자의 함정으로 제시**. 읽는 사람은 검증할 방법이 없다 |
| 4장 하루 코스 | 09:30 도착 → 12:00 합류 → 16:00 귀가 | 우리 집 아이 체력과 귀가 시간. 야간권 손님·지하철 손님에겐 무의미 |
| 4장 두 코스 | "키 큰 아이 / 작은 아이" | **형제 2명 + 보호자 2명을 전제.** 외동이거나 어른 1명이면 성립 안 함 |
| 7장 도시락 | 상온형/전자레인지형 2케이스, 메뉴 20종 | 우리 아이 식성·연령 기준 추천. 일반 가이드에 들어갈 근거가 없다 |
| 8장 먹을 곳 | "아이가 잘 먹습니다"(카레원) 같은 평 | 내 아이 이야기 |
| 지도 | 두 코스 동선 | 위와 같은 전제 |

### 남아도 되는 것

**모든 방문자에게 참인 것**만 남긴다.

- 키 구간별 어트랙션 표 (공식 데이터)
- 시설 위치·요금 (공식 데이터)
- 공연 시간표와 관람 규칙 (공식 데이터)
- 식당 목록과 가격 (사실. 단 "아이가 잘 먹는다" 같은 평은 삭제)
- 전자레인지·재입장 같은 **제도**

### 기준

> **"모든 방문자에게 참인가"**를 통과하면 본문.
> **"우리에게 참이었나"**면 본문에서 뺀다.
>
> 후자를 꼭 쓰고 싶으면 **"1회 방문 관찰"이라고 명시한 별도 박스**로 분리하고, 표본이 1이라는 것도 같이 적는다.

## 지적 2 — 루나패스를 "틀렸다"로 넘기지 말고 재조사하라

**타당하다. 재조사했고, 내가 두 번 틀렸다.**

| 시점 | 내가 쓴 것 | 실제 |
|---|---|---|
| 방문 전 | "루나패스 = 무료 앱 예약 있음. 유료 루나패스+는 안 씀" | 절반만 맞음. 제도 구조를 몰랐다 |
| 방문 후 | "**롤러코스터가 루나패스+(유료)로 전환**되어 무료 예약 불가" | **틀림.** 전환된 게 아니다 |
| 공유용 가이드 | "우선탑승권이 유료로 바뀌었을 수 있다 → 전화로 확인" | **회피.** 조사하면 알 수 있는 걸 독자에게 떠넘겼다 |

### 확정 — 두 제도가 동시에 존재한다

| | **루나패스** | **루나패스 플러스** |
|---|---|---|
| 요금 | **무료** | **유료** |
| 신설 | 기존 | **2026년 신설** |
| 어디서 | **서울랜드 앱** | **어트랙션 앞 키오스크** |
| 방식 | 시간 지정 예약 | 시간 지정 예약 (수량 확인 가능) |
| 보유 | **동시 1건만.** 쓰거나 취소해야 다음 예약 | — |
| 대기 | **예약해도 30분 이내 대기 발생 가능** | 구매 후 바로 |
| 제약 | **GPS·위치정보 동의 필수. 파크 내부에 들어와야 예약됨** (입구에서는 안 됨) | 현장 키오스크 |
| 마감 | 선착순, 조기 마감 | 수량 소진 |

**루나패스 플러스 가격 (2026)**

| 인원 | 요금 |
|---|---|
| 1~2인 | 20,000원 |
| 3인 | 30,000원 |
| 4인 | 35,000원 |
| 맨 앞/뒷자리 지정 | 1인 20,000원 |

**루나패스 플러스 적용 어트랙션**: 급류타기(후룸라이드) · 카트라이더범퍼 · **블랙홀 2000** · 라바 트위스터

### 그날 우리에게 일어난 일의 진짜 구조

무료 루나패스가 없어진 게 아니다. 우리가 노린 **블랙홀 2000이 루나패스 플러스 적용 기구**였고,
무료 예약은 **선착순 조기 마감**되었거나, **파크 안에 들어가서야 예약이 열린다는 것을 몰라** 타이밍을 놓쳤을 가능성이 크다.

> **가이드에 들어갈 문장**: "우선탑승권 정책이 바뀔 수 있으니 확인하세요"(회피) →
> "**무료 루나패스는 파크에 들어와야 앱에서 열린다. 게이트 통과 직후 바로 1건 잡아라. 동시 1건만 되고, 예약해도 30분까지 기다릴 수 있다. 급류타기·카트라이더범퍼·블랙홀2000·라바트위스터는 유료 루나패스 플러스도 함께 운영돼 무료 물량이 빨리 마감된다.**"(확정 정보)

### 참고 — 서울랜드의 "우선 탑승 제도"는 별개다

공식 FAQ: "서울랜드는 현재 **장애인, 국가유공자(상이등급 대상자)에 한하여** 우선 탑승 제도를 운영하고 있습니다."
즉 줄을 건너뛰는 **우선 탑승**과, 시간을 지정하는 **루나패스**는 다른 제도다. 루나패스를 "우선탑승권"이라 부른 것부터 부정확했다.

## 지적 3 — "유아 기구가 더 붐빈다"는 그날의 우연이다

**타당하다. 법칙 3은 폐기한다.**

내가 한 것: **1회 관찰을 법칙으로 승격**시켰다. 그리고 에버랜드 자료가 반대로 나오자 "파크 규모에 따라 반대"라는 사후 설명을 붙여 법칙을 살렸다. 이건 반증을 흡수해버린 것이지 검증이 아니다.

실제로 그날 성립한 것은 이것뿐이다:

> **2026-09-05 하루 동안, 우리가 간 시간대에, 어른 어트랙션이 비어 있었고 유아 기구는 상대적으로 사람이 많았다.**

### 혼잡도를 실제로 결정하는 것

재조사에서 나온 것 — 같은 파크에서 **오전과 오후의 손님 구성이 통째로 다르다.**

> "오전 시간에는 **태권도 등 학원단체**, 오후에는 **가족들**이 와서 하루 종일 많긴 하더라" (5월 주말 방문기)

즉 변수는 **아이 나이대**가 아니라:

| 변수 | 영향 |
|---|---|
| **그날 단체 예약** (학교·학원·종교단체) | 오전 특정 구역이 통째로 막힌다. 20인 이상 단체는 별도 창구로 예약된다 |
| **시간대** | 오전 단체 / 오후 가족 |
| **요일·시즌** | 소풍철, 방학, 공휴일 |
| **날씨** | 비 오는 날에도 사람이 많았다는 기록 있음 |
| **운휴 기구** | 점검으로 하나 닫히면 옆 기구로 몰린다 |

→ **가이드에 쓸 수 있는 것**은 "유아 기구가 더 붐빈다"가 아니라
**"혼잡도는 그날 단체 예약과 시간대가 결정한다. 앱의 어트랙션 혼잡도 화면을 보고 그때그때 움직여라."**
서울랜드 앱에 **혼잡도 확인 기능이 공식으로 있다.**

## 재조사 중 새로 발견한 오류

지적받지 않았지만 같이 틀려 있던 것들.

### ① 무료인 줄 알고 쓴 유료 시설 — 가장 심각

공식 요금표: **파크이용권은 입장과 놀이시설만.** 체험시설·코인시설·계절시설은 **별도 요금**이다.

| 시설 | 실제 요금 | 내가 쓴 것 |
|---|---|---|
| **귀신동굴** | **9,000원** | 키 조견표 "제한없음" 목록에 **무료처럼** 넣음 |
| **니나노 고카트** | 1인 6,000 / 2인 9,000 | "별도 유료"라고 표시는 함 |
| **스카이엑스** | **1인 19,000 / 2인 24,000 / 3인 29,000** | "유료 여부 확인" — **확인 가능한 걸 안 함** |
| VR게이트 | 1인 5,000~6,000 | "제한없음" 목록에 무료처럼 넣음 |
| 패들보트 | 1인 5,000 (동절기 운휴) | 무료처럼 넣음 |

**키 조견표는 "탈 수 있는가"만 보고 "돈을 더 내는가"를 안 봤다.** 조견표에 요금 열이 없는 게 구조적 결함이다.

### ② 야간권을 아예 안 다뤘다

| 구분 | 어른 | 청소년 | 어린이 |
|---|---|---|---|
| 종일권 | 52,000 | 46,000 | 43,000 |
| **야간권 (16시~)** | **45,000** | **39,000** | **36,000** |

오후에 가는 선택지가 있는데 가이드에 없었다. 유아 동반은 낮잠 때문에 오후 입장이 유리한 경우가 많다.

### ③ 요금 관련 누락

- **36개월 미만 무료** — 단 **증빙서류 지참**. 이 조건을 안 썼다
- **경로(만 65세 이상) = 어린이 요금** (신분증). 조부모 동반 가족에 큰 정보
- **장애인 및 동반 1인 50%** (종일권 어른 35,000). 국가유공자·유족도 50%
- 제휴카드 할인(본인) + 쿠폰 할인(동반인) **조합 가능**. 단 중복 할인은 불가

### ④ 주차 — "이용권 인증 시 무료"는 불완전하다

- 공식 FAQ: **티켓이 곧 주차권.** 잃어버려도 영수증·결제 문자·**당일 파크 안에서 찍은 사진**으로 동문·후문·관리동 주차장 출차 가능
- **단 서울대공원 유료 주차장은 서울랜드 관할이 아니라 별도 요금.** ← 이걸 안 쓰면 엉뚱한 주차장에 대고 돈을 낸다
- 정확한 주차 요금표는 **아직 미확인** (별도 탭)

### ⑤ 소형견 동반 가능

목줄 착용 후 안거나 애견 유모차/케이지. 실내시설·놀이시설 이용 불가, 배변봉투 필수. 가이드에 없었다.

## 구조적 문제 — 이게 근본 원인이다

개별 오류보다 이게 크다.

### 문제 1. 관찰과 사실을 섞어 썼다

바이블의 "법칙"과 가이드의 "함정"은 **1회 관찰**인데, 공식 요금·키 제한과 **같은 무게로** 적혀 있다.
읽는 사람은 어느 게 검증된 사실이고 어느 게 일화인지 구분할 수 없다.

### 문제 2. 조사하면 알 수 있는 것을 "전화로 확인하세요"로 넘겼다

루나패스가 대표 사례다. 공식 앱 안내 페이지 한 장이면 나오는 내용이었다.
**"확인 필요"는 정말 확인 불가능할 때만 쓴다.**

### 문제 3. 반증이 나왔을 때 법칙을 수정하지 않고 예외를 붙였다

법칙 3에 에버랜드 반례가 나오자 "파크 규모에 따라 반대"를 덧붙였다. 법칙을 살리려고 조건을 늘린 것이다.
**반례가 나오면 법칙을 버린다.**

### 개선 — 모든 항목에 출처 등급을 붙인다

| 등급 | 뜻 | 표기 |
|---|---|---|
| **A. 공식** | 파크 공식 자료에서 직접 확인 | 출처 링크 + 확인일 |
| **B. 교차확인** | 2차 자료 여러 건이 일치 | 몇 건이 일치하는지 |
| **C. 1회 관찰** | 우리가 한 번 본 것 | **"표본 1"이라고 명시.** 본문 아닌 별도 박스 |
| **D. 미확인** | 아직 모름 | 무엇을 어떻게 확인할지까지 적음 |

**C는 일반 가이드 본문에 들어갈 수 없다.**
