## 축을 네 개로 바꿨습니다

전 판은 "우리 집 하루"를 3인칭으로 고친 것이었습니다.
이번 판은 **모든 방문자에게 참인 것**만 남기고, 축을 넷으로 세웠습니다.

| 축 | 왜 이게 축인가 |
|---|---|
| **키** | 탈 수 있는 것이 여기서 정해진다. 50종 전수 + 존 + **보호자 동반/혼자** + 별도 요금 |
| **날씨** | 서울랜드가 조건별 운휴 시설을 공식 공개한다. **예보만 보면 그날 뭐가 서는지 안다** |
| **공식 코스** | 우산·키즈전용·초보자·스릴·멀미·캐릭터 6종. 개인 동선을 대체한다 |
| **할인** | 17종이 동시에 돌고 매달 바뀐다. **금액을 못 박는 것 자체가 틀린 접근** |

## 전 판과 달라진 것

| | 전 판 | 이번 판 |
|---|---|---|
| 1장 | 1인칭 "함정 5가지"(n=1 일화) | **키 조견표** — 존·보호자 동반·별도 요금 포함 |
| 코스 | "키 큰 아이 / 작은 아이" (형제 2명 + 보호자 2명 전제) | **공식 추천코스 6종** |
| 지도 | 우리 가족 동선 | **존과 시설 위치** |
| 도시락 | 메뉴 20종 추천 (개인 식성) | 삭제. 대신 **공식 반입 제한 목록** |
| 혼잡도 | "유아 기구가 더 붐빈다"(1회 관찰) | 삭제. **앱 혼잡도 기능 안내** |
| 우선탑승 | "유료로 바뀌었을 수 있으니 전화" | **무료/유료 두 제도의 정확한 구조** |
| 돈 | "4인 8만원" | **정가 + 진행 중 할인 17종 + 주차·코끼리열차·연간권** |
| 식당 | 8곳, "아이가 잘 먹습니다" 같은 평 | **28곳 존별 목록.** 평가는 삭제 |

## 이번 판에서 새로 들어간 것

전 판에 아예 없던 항목들입니다.

- **보호자가 같이 타야 하는 13종** — 최소 키만 보면 놓친다. 어른 1명이 아이 둘을 못 태운다
- **만 65세 이상 이용 불가 6종** — 빅회전목마·도레미악단이 포함. 3대가 가면 결정적
- **별도 요금 12종** — 스카이엑스 19,000, 귀신동굴 9,000 등. 전 판은 5종만, 그마저 무료 취급
- **날씨별 운휴 공식 표** — 기온·비·눈·바람·낙뢰
- **요일별 운영시간** — **주말은 09:30 개장**
- **야간권** (16시~, 어른 45,000)
- **주차 요금** — 인증 못 하면 30분당 2,000원
- **코끼리열차** — 파크이용권으로 무료 아님. 지하철 손님 필수 비용
- **반입 제한 공식 목록** — 텐트·버너 금지. 음식은 목록에 없음
- **크라켄 아일랜드 물놀이는 9/30까지** — 계절 시설
- **결제 수단** — 보관함 현금만 / 대여소 카드만
- **연간이용권** — 어른 220,000, 코끼리열차 포함

## 등급

본문은 전부 **A등급(공식 자료)**입니다.
**B등급**은 루나패스 플러스 요금과 예약 시점 둘뿐이고, 각주로 명시했습니다.
**C등급(1회 관찰)은 한 줄도 넣지 않았습니다.**
