## 3. 도시락

### 판을 바꾸는 사실 3가지

1. **수유실 2곳에 전자레인지·정수기가 있다** (정문 쪽 / 라바트위스터 근처). 정문 쪽에는 개수대까지. → **따뜻한 밥을 싸가도 된다.** 둘째 이유식·죽도 데울 수 있다
2. **재입장이 당일에 한해 가능하다** (나가기 전 입구 직원 안내). 동문 주차장이 코앞이라 **아이스박스를 차에 두고 점심때 가지러 가도 된다**
3. 공식 FAQ에 외부 음식 조항이 아예 없다 — 금지 문구도 없고 허용 문구도 없다. 실제로는 김밥·간식 반입과 돗자리 사용 후기가 다수. 다만 **취사·화기는 당연히 안 되고**, 현장 안내판을 한 번 보는 게 안전

### 메뉴 선택지 (골라 담기)

**주식 — 상온 안전형** (아이스박스 없이도 점심까지 버팀)

| 메뉴 | 비고 |
|---|---|
| 유부초밥 | 이 일정의 1순위. 한입 크기, 손 안 더러워짐, 더위에 강함 |
| 김밥 | 참치마요·계란샐러드 속은 빼고. 아침에 싸기 |
| 주먹밥 | 참기름·소금·김가루·볶은 멸치. 개별 랩핑하면 대기줄에서도 먹음 |
| 또띠아 롤 | 햄·치즈·양상추를 말아 은박지로. 부스러기 없음 |
| 모닝빵/베이글 샌드 | 잼 또는 햄치즈. 마요 금지 |
| 찐감자·찐고구마·옥수수 | 식어도 맛있고 안 상함. 둘째 손에 쥐여주기 좋음 |

**주식 — 전자레인지형** (수유실에서 데움)

| 메뉴 | 비고 |
|---|---|
| 즉석밥 + 밑반찬 | 컵밥처럼. 뜨거운 밥 한 끼가 아이 컨디션을 살림 |
| 볶음밥·카레·짜장 덮밥 | **국물 없는 것만.** 밀폐용기에 아침에 담기 |
| 미트볼·함박·너겟 | 데워서 반찬 겸 간식 |
| 둘째용 죽·진밥 | 3세가 지쳤을 때 가장 잘 먹힘 |

**단백질·반찬**: 삶은 계란(둘째는 노른자 반 개), 메추리알, 구운 소시지, 닭가슴살 스틱, 치즈스틱, 어묵볶음(식어도 OK)

**과일·채소**: 방울토마토·포도 **반드시 4등분**(3세 질식 예방), 오이스틱, 파프리카 스틱, 사과는 소금물에 담갔다 담기

**음료**: 물 2병 냉동 + 상온 1병, 보리차 팩. 정수기가 있으니 빈 물통 하나 챙기면 현장에서 채움

**간식**: 떡뻥·과자 1봉, 젤리 소량, 견과류는 3세 질식 위험이라 제외
