# 서울랜드 가족 나들이 가이드북

2026년 9월 5일 토요일 / 오픈런 목표 / 아빠 + 첫째 8세 + 엄마 + 둘째 3세 후반, 부모끼리 팀을 나눔

## 오늘의 결론

성공 기준은 자유이용권 4인 8만원(이미 결제) 외에 추가 지출을 거의 안 만드는 것. 주차는 이용권 인증으로 무료 처리하고, 점심은 도시락으로 해결한다. 아빠+첫째는 롤러코스터 위주, 엄마+둘째는 키즈존 위주로 팀을 나눈다.

## 1. 팀 구성과 동선

| 팀 | 구성 | 코스 |
|---|---|---|
| A팀 | 아빠 + 첫째(8세) | 롤러코스터/스릴 어트랙션 위주. 오픈런 필수 |
| B팀 | 엄마 + 둘째(3세 후반) | 키즈존/순한 놀이기구 위주. 오픈런 불필요 |

**당일 변수**: 같은 날(9/5) 여의도 한강공원(마포대교~한강철교)에서 서울세계불꽃축제 2026(13:00~22:00)이 열려 인파가 분산될 가능성. 토요일 기본 베이스는 있으니 오픈런 계획은 그대로 유지.

## 2. 오픈런 계획 (A팀 기준)

- 운영시간: 평일 10:00~19:00 / **토요일 10:00~21:00** / 일요일 10:00~20:00 (공원 사정·날씨로 변경될 수 있음. 출발 전 02-509-6000 또는 공식 앱으로 재확인)
- 게이트 도착 목표: **9:30~9:40** (개장 20~30분 전부터 줄이 생김)
- 입장 즉시 '미래의 나라'·'모험의 나라' 방향으로 직행 (입장 직후 가장 붐비는 구역)

### 스릴 어트랙션 신장 제한 (아이 실측 키로 재확인 필수)

| 최소 신장 | 놀이기구 | 8세 가능성 판단 |
|---|---|---|
| 120cm~ | 블랙홀2000, 스카이엑스, 엑스플라이어, 알포스윙 | 대부분 가능. 우선 공략 |
| 110cm~ | 킹바이킹, 락카페 | 가능 |
| 140cm~ | 도깨비바람, 샷드롭 | 8세 평균키(125~130cm)로는 어려울 수 있음. 실측 후 판단 |

## 3. 키즈존 (B팀, 오픈런 불필요)

빅회전목마, 둥실비행선, 깜부비행기, 도레미악단, 피터팬(보호자 동반 시 유아 탑승 가능), 쥬라기랜드, 시티패럿, 웰컴투카니발. 대기가 짧은 구역이라 여유 있게 움직여도 된다.

**참고**: 자유이용권에 동물원은 미포함. 이번 계획엔 해당 없음.

## 4. 주차

| 항목 | 내용 |
|---|---|
| 위치 | 서울랜드 동문 주차장 (경기도 과천시 광명로 181, 국립현대미술관 진입로 방향) |
| 기본 요금 | 중소형 30분당 2,000원 (카드결제만) |
| **무료 조건** | **당일 이용권/영수증으로 1일 1회 무료.** 출차 전 사전정산기에서 인증 필수 |

## 5. 도시락 (식대 절감 핵심)

- 외부 음식/도시락 반입 가능. 벤치·테이블 다수 (공식 "피크닉존" 명칭은 없음, 벤치 자유 이용)
- 점심시간(12~13시) 식당가는 혼잡하지만 도시락이면 상관없음 — 아무 벤치에서 먹으면 됨
- **주의**: 코스터 라이딩 직전 과식하면 멀미 위험. A팀은 가볍게 먹고 탑승

**메뉴 제안**: 김밥/삼각김밥 + 주먹밥, 샌드위치, 씨 없는 과일(포도·방울토마토), 얼린 물(아이스박스 대용), 물티슈.

## 7. 출발 전/현장 체크리스트

- [ ] 첫째 실측 키 재기 (140cm 이상인지 확인 → 도깨비바람/샷드롭 가능 여부)
- [ ] 출발 전 서울랜드 운영시간 재확인 (02-509-6000 또는 공식 앱, 날씨 변수)
- [ ] 도시락·물(얼려서)·물티슈 준비
- [ ] 자유이용권/영수증 챙기기 (주차 무료 인증용)
- [ ] 미끄럼방지 양말은 불필요, 대신 편한 운동화

**최종 문장**: 오픈런으로 스릴 라인업 먼저 잡고, 도시락으로 점심을 해결하면 8만원 안에서 하루를 채울 수 있는 날입니다.
