## 5. 주차장 전략 — 하중도 주차장 (공식 EN 페이지 원문, A등급)

> **구조가 다른 파크와 다르다.** 주차장이 입구 바로 앞이 아니라 좀 떨어져 있어서, **걸어서 가는 방법과 셔틀버스, 둘 다 있다.** 어느 구역에 대느냐에 따라 유리한 쪽이 갈린다.

**공식 리조트 가이드 PDF의 주차 위치도** (`assets/legoland_parking_map.png`) — 하중도 전체에 **주차장(P)이 하나**다. 번호로 나뉜 여러 주차장이 아니라, 큰 단일 주차장을 색깔 구역으로 나눠 쓰는 구조. **이 공식 도식 자체가 P에서 입구까지의 도보 경로를 화살표로 표시**하고 있다 — 즉 걷는 것도 공식적으로 안내되는 방법이다. 색깔 구역별 정확한 위치까지는 이 도식에 없어 현장 안내판이 최종 근거다.

### 어디에 대야 제일 가까운가 — 구역 배치도까지 확보

**공식 리조트 가이드의 위치도(§주차장 지도)는 "P가 하나"라는 것만 보여줄 뿐, 색깔 구역 배치까지는 없다.** 그래서 2022년 개장 당시 촬영된 현장 안내판 사진(`assets/legoland_parking_zone.png`, changehomes.co.kr 블로그, B등급)을 확보했다.

> 이 사진에 적힌 주차요금(1시간 무료, 2h 3,000원…5h+ 12,000원)이 오늘 확인한 **공식 최신 요금과 정확히 일치**한다. 요금처럼 검증 가능한 값이 맞으니, 구역 배치라는 검증 불가능한 부분도 신뢰도를 올려 잡았다 — AUDIT ⑲의 "출처 안에서 검증 가능한 값부터 대조" 원칙 적용.

**레이아웃**: 왼쪽 블록(BUS·RED·GREEN·BLUE) + 오른쪽 블록(YELLOW·ORANGE·PINK), 두 블록 사이 중앙통로에 **"현위치" 표시 = 셔틀정류장**이 있다.

### 🔴 정정 — "제일 가까운 자리"는 질문이 두 개였다

셔틀정류장 위치(BLUE-YELLOW 사이)와 **"걸어서 제일 가까운 곳"은 다른 질문**인데 하나로 취급했었다. 반복해 나오는 2차 출처는 **PINK가 입구까지 도보로 가장 가깝다**고 말한다 <B등급, 복수 출처 일치>.

| 항목 | 내용 |
|---|---|
| **걸어갈 거면** | **PINK** — 입구까지 도보 최단 거리라는 게 반복되는 정보 |
| **셔틀 탈 거면** | BLUE·GREEN(왼쪽) 또는 YELLOW·ORANGE(오른쪽)의 중앙통로 쪽 칸 — 정류장이 이 통로에 있음 |
| **전기차 충전(공식 A등급)** | "주차장 관리사무소 근처", 완속 35기+급속 5기(총 40기). 2차 출처는 **PINK 구역 우측 상단**이라고 특정 |
| 전기차 할인 | **없음** — 경차·장애인차도 동일 요금 <A등급> |
| 사전정산기 | ORANGE·PINK 구역 우측 하단, 총 3대(2차 출처) |

**PINK가 걸어서 가깝고 충전기까지 있다면, 우리 가족(전기차·웨건)에겐 사실상 최적 조합이다.** 도보로 가면 **"웨건을 셔틀에 실을 수 있는지" 확인 못 했던 문제 자체가 없어진다** — 처음부터 셔틀을 안 타면 되니까.

**다만 정확한 도보 거리·소요 시간은 어느 출처에도 숫자로 안 나온다** <D등급>. 일반적으로 "주차장에서 200~300m, 약 5분"이라는 통상적인 수치만 있다. **PINK가 그 최단 케이스인지, 평균치인지는 확인 못 했다.**

**안내 요원이 배정하는 구역은 그날그날 다르다.** RED나 다른 구역으로 배정받으면 셔틀을 타는 게 낫다. **이 사진은 2022년 자료라 구획 번호는 바뀌었을 수 있다 — 현장 표지판이 최종 기준.**

### PINK 구역 자체는 "전기차 전용"이 아닌 것으로 보인다

2차 출처 문구를 다시 보면 **ORANGE는 "친환경 자동차 주차 구역"이라고 명확히 규정**하는 반면, **PINK는 "전기차 충전기가 구비된 주차구역"이라고만 표현**한다. 즉:

- **ORANGE = 저공해차 전용 구역**(일반 내연차 주차 시 문제 소지)
- **PINK = 일반 주차 구역인데, 그 안(우측 상단)에 충전기 몇 대가 있는 구조로 보인다** <C등급, 표현 차이에 근거한 추론 — 확정 못 함>

법적으로 **전기차 충전구역(그 몇 자리)엔 내연차가 대면 안 되지만, 우리 차는 전기차라 이 문제 자체가 해당 없다.** PINK 구역에 배정받아도 그냥 대면 된다 — 다만 충전소 코앞 칸이 아니면 충전기까지 걸어가야 할 수 있다는 정도만 유의.

## 6-B. 동선 검증 — 구간 순서를 바꾼 이유

**공식 파크맵에 동선을 표시한 그림**: `assets/legoland_route_final.png`(전체 개요) · `assets/legoland_detail_castle.png`(캐슬 확대) · `assets/legoland_detail_city.png`(시티 확대) · `assets/legoland_detail_bricktopia.png`(브릭토피아·브릭스트릿 확대). 확대판은 공식 파크맵 원본 해상도(3392×2386)에서 잘라내 픽셀 좌표로 정확한 위치를 확인한 것 — 특히 시티 확대판의 4D 시네마 핀은 실제 지도 그림의 "CINEMA" 간판 위치와 일치해 좌표가 맞다는 걸 교차 확인함

**공식 파크맵 자체가 "맵은 실제 스케일이 아닙니다"라고 명시**하고 있어 <A등급, 맵 원문 표기> 미터 단위 거리는 잴 수 없다. 대신 **구역 배치(토폴로지)는 맵에서 그대로 읽을 수 있다** — 이걸로 기존 계획의 동선 낭비를 찾아냈다.

**구역은 입구를 기준으로 한 방향 루프에 가깝다**: 입구 → 브릭스트릿 → 브릭토피아 → LEGO 캐슬(드래곤) → NINJAGO 월드 → 미니랜드 → 해적의 바다 → LEGO 시티 → (다시 입구). 캐슬과 시티는 이 루프에서 **정반대 끝**이다.

**기존 초안의 문제**: 개장 직후 드래곤(캐슬) → NINJAGO → 점심 → **브릭토피아(뒤로 후퇴)** → **LEGO 시티(다시 정반대 끝까지 전진)** → **드래곤 2차(다시 캐슬로 후퇴)** → 브릭스트릿. 캐슬↔시티를 사실상 **왕복 3번** 건너는 구조였다.

**수정한 순서**: 캐슬(드래곤 1차) → NINJAGO(인접) → 미니랜드·해적의 바다 통과 → 시티(점심+라이드+영화, 전진 1회) → 캐슬로 귀환(드래곤 2차, 후퇴 1회) → 브릭토피아(캐슬과 인접) → 브릭스트릿(브릭토피아와 인접) → 출구. **캐슬↔시티 왕복을 1번으로 줄이고, 브릭토피아는 순서상 원래 자리인 캐슬·브릭스트릿 사이로 되돌렸다.**

> **이동 소요시간은 추정치다 <D등급>.** 맵이 스케일을 보증하지 않아 "인접 구역=3~5분", "캐슬↔시티 편도(구역 3~4개 통과)=12~15분"으로 가정했다 — 일반적인 소형~중형 테마파크의 도보 속도 기준. **10:00~10:05 첫 이동(입구→캐슬)에서 실제 시간을 재서, 뒤 구간들을 그 비율로 조정**하는 걸 권장한다.
