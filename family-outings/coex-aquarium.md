## 2. 어디에 대는가 — 코엑스 공식 주차지도를 직접 읽었다

### 🔴 먼저 정정 — 초판에 옮겨 적은 "블루존 18~20구역"은 공식 지도와 맞지 않는다

씨라이프 FAQ 원문은 이렇다.
> "아쿠아리움에서 가까운 주차장은 **코엑스몰 북문 주차장**이며 **지하2층 블루존 18~20구역**입니다."

그런데 **코엑스 공식 B2 주차지도**(`coex.co.kr/wp-content/uploads/2026/03/map-store-b2.png`, 6871×4765)를 받아 읽으니 다르다.

| 지도상 색 | 구역 번호 | 위치 |
|---|---|---|
| **초록** | **15~25** | 트레이드타워 · 별마당 도서관 (서쪽, 삼성역 방향) |
| 보라 | 26~39 | 도심공항타워 · 전시컨벤션센터 중앙 |
| **파랑(블루)** | **40~65** | **그랜드볼룸 · 영화관 · 아쿠아리움** (동쪽, 봉은사역 방향) |
| 주황 | 48~65 (하단) | 아셈타워 전용 |

**18~20은 초록 구역이고 아쿠아리움 반대편이다.** FAQ의 "블루존 18~20"은 옛 체계이거나 오기로 보인다.
**색(블루존)은 맞고 번호가 틀렸다.** 지도를 따른다. <A등급 — 공식 지도>

### 아쿠아리움에 가장 가까운 자리

> **B2 블루존 52G ~ 60G.** 바로 앞이 **P7 에스컬레이터**이고, 옆에 "영화관 전용 출입구"가 있다.

지도에 그 구역 위쪽으로 **「그랜드볼룸 | 영화관 | 아쿠아리움」**이라고 적혀 있다.

### 🔴 5판 정정 ② — 아쿠아리움은 **B1**이다. 같은 층이 아니다

5판에 나는 *"아쿠아리움도 B2라 같은 층, 수평 이동만 하면 된다"*고 썼다. **틀렸다.**
공식 B2 주차지도 **범례**를 확대해 읽으니 P5·P7의 연결 표기가 이렇다.

> P7 — `1F` 그랜드볼룸 / **`B1` 영화관 | 아쿠아리움** / 스타필드 코엑스몰
> P5 — `1F` 전시컨벤션센터 로비 / **`B1` 영화관 | 아쿠아리움** / 스타필드 코엑스몰

**B2에 대고 → P7에서 한 층 올라가 B1.** 층 표시를 안 읽고 "같은 층"이라고 단정한 것이다. <A등급 — 공식 지도 범례>

### 🔴 그리고 P7에는 **엘리베이터가 없다** — 유아차가 있으면 P5

같은 범례의 아이콘을 하나씩 확인했다.

| 출입구 | 에스컬레이터 | 엘리베이터 | 유아차 |
|---|---|---|---|
| **P7** (가장 가까움) | **B4~1F** | **없음** | **곤란** |
| **P5** | B4~3F | **B4~1F 있음** | **가능** |
| P6 (아셈타워) | — | B4~1F | 코엑스몰 이동 불가 |

**유아차를 가져가면 P7이 아니라 P5 쪽에 댄다.** P5는 B2 지도상 44~51번 열 근처로, 52G~60G보다 조금 멀지만 엘리베이터가 있다.
유아차 없이 3세를 안고 간다면 **P7이 가장 짧다**. <A등급 — 공식 지도 범례 아이콘>

### B2 엘리베이터/출입구 7곳 — 아쿠아리움은 P5·P7뿐

| P | 색 | 연결 시설 | 층 |
|---|---|---|---|
| P1 | 초록 | 트레이드타워 · 스타필드 · 코엑스아티움 | B2~B1 |
| P2 | 초록 | 별마당 도서관 · 스타필드 · 트레이드타워 | B2~B1, B2~1F |
| P3 | 보라 | 전시컨벤션센터 로비 · 스타필드 | B2~1F |
| **P4** | 보라 | 전시컨벤션센터 로비 · 스타필드 | **B2~RF (옥상)** |
| **P5** | 파랑 | 전시컨벤션센터 로비 · **영화관·아쿠아리움** · 스타필드 | B4~3F, B4~1F |
| P6 | 주황 | 아셈타워 **전용** (B1 스타필드로 이동 불가) | B4~1F |
| **P7** | 파랑 | 그랜드볼룸 · **영화관·아쿠아리움** · 스타필드 | B4~1F |

**「아쿠아리움」이 적힌 건 P5와 P7 둘뿐이다.**

### 출구 GATE — 나갈 때 쓰는 번호

공식 B2 지도의 노란 `≪ 출구 / Way Out` 표기다. **들어갈 때 쓰는 이름이 아니다**(§2-C).

| 출구 GATE | 도로 |
|---|---|
| GATE 1 · 2 · 3 | **영동대로** |
| **GATE 4** | **봉은사로** ← 우리 자리에서 가장 가깝다 |
| GATE 5 | 아셈로 |

- 아쿠아리움 내부 B2 지도의 **`P` 주차등록(Parking Registration)** 아이콘 — 무지개 라운지(2) 위쪽. **할인 등록 키오스크는 여기다.**

## 2-C. 입구 — 도로에서 자리까지 (6판 신규)

> 물어보신 부분이다. **"코엑스 주차장 입구도 중요하더라."** 맞다. 그리고 여기서 5판의 오류가 하나 나왔다.

### 🔴 코엑스에는 번호가 다른 두 체계가 있고, 나는 그걸 섞어 썼다

5판에서 나는 "GATE 4(봉은사로)로 **진입**하라"고 썼다. 공식 자료를 각각 원문으로 받아 보니 이렇다.

| 체계 | 무엇인가 | 표기 |
|---|---|---|
| **진입로(들어가는 곳)** | 코엑스 공식 「주차장 입구 안내」 지도 | **이름**으로만 부른다 — 서문 / 동문 / 북문 / 트레이드타워 / 아셈타워 GATE. **번호가 없다** |
| **출구(나가는 곳)** | 코엑스 공식 B2 주차지도 범례의 `≪ 출구 / Way Out` | **번호**로 부른다 — GATE 1·2·3(영동대로) / GATE 4(봉은사로) / GATE 5(아셈로) |

**GATE 1~5는 나가는 문이다.** 들어갈 때 내비에 찍을 "GATE 4"는 없다. <A등급 — 코엑스 공식 지도 2종>

씨라이프가 말하는 "북문(GATE 4)"은 **같은 봉은사로 쪽 램프를 출구 번호로 부른 것**이다. 도로는 맞고 부르는 이름이 달랐다.

### 진입 GATE 5개 — 공식 「주차장 입구 안내」 지도

| 진입 GATE | 접한 도로·랜드마크 | 어디로 들어가나 |
|---|---|---|
| **코엑스 서문 GATE** | 봉은사 사거리 쪽 · 세븐럭 카지노 앞 | **옥상(RF) + 지하 전부** |
| **코엑스 북문 GATE** | **봉은사로 — 봉은사 건너편** | 지하 |
| 코엑스 동문 GATE | 라이브플라자 앞 | 지하 (전시장 방문용) |
| 트레이드 타워 GATE | 삼성역 쪽 | 지하 (트레이드타워용) |
| 아셈타워 GATE | 아셈플라자 앞 | 지하 (**아셈타워 전용**) |

### 🔴 7판 정정 — 6판의 "아셈타워 GATE는 쓰면 안 된다"는 틀렸다

**들어가셨던 게 맞다.** 제가 근거로 든 경고문은 **게이트 이야기가 아니었다.**

> *"본 출입구는 아셈타워 전용으로 **B1 스타필드 코엑스몰로 이동 불가**하오니 다른 입구 이용바랍니다."*

이 문장은 B2 지도의 **`P6` 배지**에 붙어 있다. P6는 **차가 들어가는 램프가 아니라, 주차장에서 건물로 걸어 나가는 출입구**(엘리베이터 B4~1F, 1F 아셈타워행)다.
**"다른 입구"도 다른 게이트가 아니라 다른 보행 출입구(P5·P7 등)를 말한다.**

그리고 결정적으로, **코엑스 공식 「주차장 입구 안내」의 '코엑스몰' 지도에는 아셈타워 GATE가 강조 표시 5개 중 하나로 들어 있다.** 즉 코엑스 스스로 코엑스몰 진입로로 인정한다. 제가 인용한 그 지도에 답이 있었는데 배지 하나를 게이트로 잘못 읽었다. <A등급 — 같은 공식 지도>

**그럼 진짜 주의할 것은 무엇인가.**

| 잘못된 규칙(6판) | 맞는 규칙(7판) |
|---|---|
| 아셈타워 GATE로 **들어가지 마라** | 아셈타워 GATE로 **들어가도 된다** |
| — | 들어간 뒤 **주황(아셈타워) 구역에 대지 마라.** 거기 보행 출입구는 P6뿐이고, P6로는 코엑스몰에 못 간다 |

**아셈타워·동문 GATE로 들어가면 생기는 실제 비용은 "금지"가 아니라 "횡단"이다.**
두 게이트는 아쿠아리움 반대쪽 끝에 붙어 있어서, **주황 구역을 지나 블루존(52G~60G)까지 주차장 안에서 차로 가장 길게 가로질러야 한다.** 주말에 이 구간이 서면 "주차가 힘들다"가 된다.
→ 그래서 **북문 GATE**를 권하는 이유는 "다른 데는 안 된다"가 아니라 **"들어가자마자 블루존"**이기 때문이다.

### 목적지별 공식 답 — 코엑스가 직접 알려준다

코엑스 주차안내 페이지의 「주차장 입구 안내」는 **층별·목적지별로 다른 지도**를 띄운다. 그 지도 파일을 직접 받아 읽었다.

| 고르면 | 공식 지도가 강조하는 진입 GATE |
|---|---|
| **옥상(RF)** | **서문 GATE 하나뿐** |
| **B2** = **코엑스몰** | **5개 전부** (서문·북문·동문·트레이드타워·아셈타워) |

즉 **B2는 "아무 데로 들어와도 된다"**가 코엑스의 공식 입장이다. 옥상만 서문으로 한정된다. <A등급>
(5판에 B등급으로 적었던 "옥상은 서문 GATE 진입 후 지상 3층"은 **이걸로 A등급이 됐다**.)

### 그래서 아쿠아리움은 어디로 들어가나 — **북문 GATE**

공식이 5개를 다 열어놨으니 결정은 **"어느 문이 아쿠아리움에 가장 가까운가"**다. 근거 3개가 한 방향을 가리킨다.

1. **씨라이프 공식**: *"아쿠아리움에서 가까운 주차장은 **코엑스몰 북문 주차장**"*
2. **씨라이프 공식 단체 안내**: *"코엑스북문 4번 GATE(**봉은사 반대편**)"* / *"코엑스 북문(GATE 4) 하차 시 **직원이 아쿠아리움까지 인솔**"*
3. **코엑스 공식 B2 지도**: 북문 바로 안쪽이 **그랜드볼룸 | 영화관 | 아쿠아리움** 구역이고, 그 앞이 **P7**이다

세 개가 같은 지점을 말한다. → **북문 GATE → B2 → 52G~60G → P7.** <A등급>

### 하남 미사에서 오는 길 — 어디서 북문으로 붙나

코엑스 공식 「오시는 길」에서 북문으로 가는 경로는 둘이다. <A등급 — 원문>

> **영동대교 방면 1**: 영동대교를 건너서 경기고 및 청담역 사거리 직진 → **코엑스사거리에서 우회전, 봉은사사거리에서 유턴하여 북문 GATE**를 통하여 코엑스 지하주차장 진입.
> **강남고속터미널 방면 2**: 교보타워 사거리에서 직진하여 라마다 호텔을 지나 직진 → **봉은사사거리에서 우회전 후 100m 직진하여 우측에 있는 북문 GATE**를 통하여 코엑스 지하주차장으로 진입.

미사에서는 올림픽대로 → 영동대교가 자연스럽다. 즉 **위쪽(영동대교 방면 1)**이 우리 경로다.

## 2-B. 옥외 주차장(옥상 RF) — 도면을 직접 세어 분석했다 (7판 전면 개정)

> 요청하신 부분이다. 6판까지는 "옥상은 적다"고만 썼다. **적다는 게 몇 면인지 세지 않고 쓴 건 어림값이다.** 이번에는 셌다.

### 몇 면인가 — **일반 425면**

코엑스는 주차 대수를 공개하지 않는다(요금·층별정보 페이지 어디에도 없다). 그래서 **공식 RF 도면(6865×4717)에서 직접 계수**했다.

| 구분 | 면수 | 근거 |
|---|---|---|
| **일반** | **425면** | 도면의 흰색 주차 칸을 연결성분으로 계수 |
| 전기차 | **53면** (급속 6 · 완속 47) | **코엑스 공식 표기** — 급속 해피차저, 완속 에버온 |
| 장애인 | 약 13면 (4구획) | 도면의 파란 구획 면적 ÷ 1면 면적 |
| **합계** | **약 490면** | |

**계수 방법과 검증** <B등급 — 공식 도면 실측, 원자료는 A등급이나 계수는 내 작업>
- 크롭 범위를 세 번(400~1000 / 380~1020 / 360~1050) 바꿔도 **425로 불변**.
- 한 열(왼쪽 끝 기둥 열)을 **눈으로 세니 28면**, 알고리즘도 **28**.
- 칸 크기는 도면 축척으로 **약 3.2 × 6.8 m** — 실제 주차면 규격과 맞는다.
  (축척은 도면의 삼성역·봉은사역 표시 사이 **실거리 666m**(Nominatim 좌표)로 환산 = 0.108 m/px)

> **⚠️ 같은 방법을 지하에는 쓸 수 없다.** 지하 도면의 색칠 상자(52G, 53G…)는 **1면이 아니라 구획 표시**다. 한 상자가 약 11 × 6.5 m로 주차면의 두 배가 넘는다. 실제로 B2+B3+B4를 그 방식으로 세면 664개밖에 안 나오는데, 2차 출처들이 말하는 "4,800여 대"와 7배 차이다.
> **그래서 "지하가 몇 면"은 쓰지 않는다.** 셀 수 있는 것만 셌다.

즉 **옥상 약 490면은 코엑스 전체(2차 출처 기준 4,800여 대)의 10% 안팎**이다. 주말에 금방 찬다.

### 아쿠아리움까지 얼마나 먼가 — **약 5.5배**

같은 축척으로 도면에서 재봤다. <C등급 — 도면 실측, 보행 경로가 아니라 직선거리>

| | 보행 출입구 | 아쿠아리움까지 직선 | 층 이동 |
|---|---|---|---|
| **지하 B2 블루존 52G~60G** | **P7** | **약 43 m** | B2 → **B1 한 층** |
| 옥상 RF | P9 | **약 236 m** | RF → **B1** |
| 옥상 RF | P4 | 약 245 m | RF → B1(또는 1F) |

옥상 주차 구획 자체가 **도심공항터미널 쪽(서편)에 몰려 있고**, 아쿠아리움은 반대쪽 끝이다. 옥상에는 아쿠아리움 쪽 구획이 아예 없다.
P9·P4 표기도 **「1F 전시컨벤션센터 로비 / B1 스타필드 코엑스몰」**까지다 — **아쿠아리움 표기가 없다.** B1에 내려서 몰을 가로질러 걸어야 한다.

### 그런데 옥상에만 있는 장점이 두 개 있다

| | 지하 B2(최단 P7) | **옥상 RF** |
|---|---|---|
| **엘리베이터** | **P7에는 없다 — 에스컬레이터뿐** | **P4·P9 둘 다 엘리베이터** |
| **전기차 충전** | 현재 공식 페이지에 지하 표기 없음 | **급속 6 · 완속 47 — 코엑스에서 여기뿐** |
| 진입 줄 | 지하 램프 — 여기가 막힌다 | **서문 GATE에서 지상 3층으로 올라간다 — 지하 줄과 안 섞인다** |
| 출구 | GATE 1~5 다수 | **GATE 5(아셈로) 하나** |
| 요금 | 15분 1,500원 | **동일** |
| 날씨 | 영향 없음 | **비·눈·직사광 노출** |
| 진입 GATE | 5개 전부 | **서문 GATE 하나뿐** |

### 결론 — 옥상이 답이 되는 경우는 셋뿐

**아쿠아리움만 갈 거면 지하 B2 블루존이 맞다. 이미 제대로 대셨다.**
옥상은 아쿠아리움까지 5배 이상 멀고, 유아차로 몰을 200m 넘게 가로질러야 한다.

**그래도 옥상으로 가야 하는 경우:**
1. **지하 진입 줄이 길 때** — 옥상은 서문에서 지상으로 올라가는 길이라 지하 램프 대기와 섞이지 않는다.
2. **전기차를 충전해야 할 때** — 코엑스에서 충전기가 있는 층은 옥상뿐이다. **이 집 차가 전기차라 이게 상시 조건이 됐다 → §2-D**(급속 1시간 규정 주의).
3. **유아차가 있는데 P5 근처가 만차일 때** — P7은 에스컬레이터뿐이라, 엘리베이터가 꼭 필요하면 P5 아니면 옥상이다.

**단 1·3번은 "옥상도 490면뿐"이라는 제약과 맞물린다.** 지하가 찰 정도면 옥상은 이미 찼을 가능성이 높다. **출발 전 만차 예측(§3)이 먼저다.**

→ **어제 힘들었던 게 "진입 대기"였다면, 답은 층을 바꾸는 게 아니라 ①진입 게이트를 북문으로 바꾸고 ②출발 전 만차 예측을 보는 것**이다. (→ §2-C)

## 2-D. 전기차라면 — 계산이 달라진다 (8판 신규)

> **"항상 자리 있을까"**가 질문이셨다. 정직한 답부터: **아무도 사전에 알 수 없다. 다만 출발 전에 실시간으로 볼 수는 있다.**
> 그런데 조사하다 **자리보다 먼저 걸리는 게** 나왔다.

### 🔴 먼저 — **급속에 대면 안 된다. 이 계획은 전부 과태료다**

**환경친화적 자동차법의 「충전방해행위」** <A등급 — 법제처 찾기쉬운 생활법령>

| 구분 | 허용 주차 시간 |
|---|---|
| **급속충전시설** | **1시간** |
| 완속충전시설 — 전기차 | **14시간** |
| 완속충전시설 — 외부충전식 하이브리드(PHEV) | **7시간** (2026-02-05 시행) |

- 초과 주차는 **충전방해행위**다. 법정 과태료 **100만원 이하**(실제 부과는 10만원이 일반) <B등급>
- 적용 대상: **공공건물·공중이용시설**, 공동주택(100세대 이상), 지자체 주차장 등 → **코엑스는 공중이용시설이다**

**우리 시간표를 대보면 전부 걸린다.**

| 안 | 체류 | 급속(1시간) | 완속(14시간) |
|---|---|---|---|
| A안 | 3시간 55분 | **✗ 2시간 55분 초과** | ○ |
| B안 | 4시간 25분 | **✗ 3시간 25분 초과** | ○ |
| C+안 | 3시간 50분 | **✗ 2시간 50분 초과** | ○ |

> **전기차로 아쿠아리움에 가면 답은 하나다 — 완속에 댄다.** 급속이 비어 있어도 대면 안 된다.
> 충전만 하고 지하로 옮기는 2단계도 이론상 가능하지만, **아이 둘 데리고 1시간 안에 차를 빼서 다시 대는 건 비현실적**이다.

### ① 코엑스는 전기차 주차 감면이 **없다**

공식 요금표를 원문으로 확인했다. 감면 항목은 **「장애인, 국가유공자 주차요금 50% 할인」 하나뿐**이고, **저공해차·전기차 감면은 없다.** <A등급 — 코엑스 공식 요금표>

→ **충전하는 동안에도 주차요금은 그대로 나간다.** 아쿠아리움 할인 4시간 4,800원은 전기차든 아니든 같다.
→ 가성비만 보면 **충전 자체가 목적이면 하남에서 하고 오는 게 낫다.** 코엑스 옥상 충전은 **"어차피 4시간 세워둘 거니까 덤으로"** 정도가 맞다.

### ② 몇 대인가 — 공식과 2차 데이터가 정면으로 충돌한다

| 출처 | 급속 | 완속 | 위치 |
|---|---|---|---|
| **코엑스 공식 주차안내** <A> | **6대** (해피차저) | **47대** (에버온) | **둘 다 옥상 RF** |
| 일렉베리 — 해피차저 데이터 <D> | 6대 DC콤보 50kW, 24시간 | — | **지하 3층 라이브존 「퍼플01~08 기둥」** |
| 일렉베리 — 에버온 데이터 <D> | — | **3대** 7kW | 지상 **옥상층 입구 좌측 계단 앞** |
| 코엑스 페이지 HTML — **숨겨진 줄** | — | "코엑스 지하3층 라이브존 주차장 / 완속 9대(옥상 주차장) 보유" | **주석 처리돼 화면에 안 나온다** |

**"어느 쪽이 맞나"보다 "같은 걸 세고 있나"를 먼저 물어야 한다.**
- **급속 6대는 양쪽 다 "해피차저 6대"**다. 같은 설비를 두 곳으로 적었을 가능성이 크다.
- **완속 47 vs 3**은 등록 단위 차이로 보인다 — 옥상 전체 vs "계단 앞" 한 구역.
- 결정적으로, **일렉베리가 적은 코엑스 주차요금(30분 2,400원·일 18,000원)은 코엑스 공식(15분 1,500원·일 60,000원)과 다르다.** 그 플랫폼의 코엑스 데이터는 **갱신이 늦다**고 봐야 한다.

**그래서 확정하지 않는다.** 대수·위치는 **출발 전 앱 확인이 유일한 답**이다. <D등급>

**참고로 내 실측**: 공식 RF 도면의 초록(전기차) 구획 면적을 1면으로 나누면 **약 57면**이 나온다. 공식 표기 53면(급속6+완속47)과 가깝다 → **옥상에 50면대가 있다는 쪽은 서로 맞는다.** 위치가 갈리는 건 급속 쪽이다.
구획은 **4덩어리**로 흩어져 있다(약 11면 / 19면 / 19면 / 8면).

### ③ 출발 전 3분이면 실시간으로 보인다

- **무공해차 통합누리집 `ev.or.kr`** — 전국 충전기 실시간 운영현황
- **에버온 앱**(옥상 완속) ☎1661-7766 · **해피차저 앱**(급속)
- 통합 앱에서 **"코엑스" / "코엑스옥상"**을 찍으면 **충전 가능 n기 / 충전 중 n기**가 그대로 나온다
  (조사 중 실제로 *"충전 가능 1개, 충전 중 2개"*가 표시됐다 — 2026-09-21, **표본 1회 관찰 C등급**)
- **§3의 코엑스 만차 예측과 같이 본다.** 둘 다 출발 전 한 번이면 된다.

### ④ 전기차라 유리한 점도 있다

**충전구역은 내연차가 주차하면 과태료 대상**이다(법정 200만원 이하, 실제 10만원). 그래서 **일반 구역이 만차인 날에도 충전구역은 비어 있는 경우가 있다.**
"항상 자리 있을까"의 답은 **"일반 자리보다는 확률이 높다"**까지는 말할 수 있다. 그 이상은 실시간을 봐야 한다.

### ⑤ 아쿠아리움 4,800원 할인이 옥상에서도 되나

공식 요금표에 **층 구분이 없다.** 그리고 할인 방식이 **아쿠아리움 내부 기기에 차량번호를 등록**하는 것이라 **주차한 층과 무관**하다고 보는 게 자연스럽다. <B등급 — 추론. 공식이 "옥상 제외"라고 쓴 적은 없다>
다만 명시 문구를 못 찾았으니, 옥상에 대셨다면 **등록 후 사전 정산기에서 금액을 한 번 확인**하시는 게 안전하다.

### ⑥ 결론 — 전기차 가족의 선택표

| 상황 | 어디에 대나 |
|---|---|
| **충전이 꼭 필요하다** | **옥상 완속.** 4시간 관람 = 완속 4시간 충전, 14시간 제한 안. P9 엘리베이터로 B1 → 아쿠아리움까지 약 236m |
| **충전이 급하지 않다** | **지하 B2 블루존 52G~60G.** 아쿠아리움까지 43m. 충전은 하남에서 |
| **유아차가 있다** | **옥상이 오히려 나을 수 있다** — P9은 **엘리베이터**, 지하 최단 P7은 **에스컬레이터뿐** |
| **급속만 비어 있다** | **대지 마라.** 1시간 넘기면 과태료다 |

## 8. 확인하지 못한 것

| 항목 | 상태 |
|---|---|
| 주차 할인 **4,800원 vs 6,000원** | 씨라이프 **공식 FAQ는 4,800원**. 일부 2차 출처가 6,000원이라 함 → **공식 채택** |
| 코엑스 주차장 **총 대수** | **공식 페이지 어디에도 없다**(요금·층별정보·주차안내 3개 페이지 확인). 2차 출처가 "4,800여 대"라 하나 원문 확인 불가 → D등급 |
| 지하 B2·B3·B4 **층별 면수** | 도면의 색칠 상자가 1면이 아니라 구획 표시라 **셀 수 없다.** 같은 방법으로 세면 3개 층 합 664개로 2차 출처와 7배 차이 — 그래서 쓰지 않았다 |
| 옥상 RF **공식 면수** | 없음. 이 문서의 **425면은 공식 도면을 내가 계수한 값**이다(검증 2회). 공식 수치가 아니다 |
| 주말 **구체적 만차 시각** | 실시간 데이터라 사전 고정값 없음 — **당일 확인이 정답** |
| ~~"북문"이 GATE 몇 번인지~~ | **6판에서 해결.** 진입로는 **이름**(서문·북문·동문·트레이드타워·아셈타워), 출구는 **번호**(GATE 1~5). 씨라이프의 "북문(GATE 4)"은 같은 봉은사로 램프다 → §2-C |
| **GBB 12,000원의 단위** | 공식 원문이 "먹이 포함 12,000원"이라고만 쓰고 **1인/보트 구분이 없다.** 4인이면 12,000 vs 48,000으로 4배 차이 → **현장 또는 ☎02-700-7200** |
| **GBB 예약만 걸고 나중에 탈 수 있는지** | 원문은 "체험존에서 현장 예약만 가능"까지만 말한다. C+안의 28분 대기 리스크가 여기 달려 있다 |
| **GBB 보트 1대 정원 / 보호자 동반 인원** | 공식에 없음. 4인 가족이 한 번에 타는지 미확인 |
| **VR 체험존의 정확한 위치** | "⑥ 해양 디스커버리 인접"은 **현장 사진 1장 근거(C등급)**. 공식 페이지는 주소만 적고 구역을 안 밝힌다 |
| 내비에서 **"코엑스 북문"** 검색 결과 | 앱마다 다를 수 있어 확인 못 함 — 출발 전에 한 번 찍어보시는 게 확실 |
| 씨라이프 FAQ의 **"블루존 18~20구역"** | 공식 지도와 불일치(18~20은 초록). 색은 맞고 번호가 틀린 것으로 보이나 **확정은 02-700-7200 문의** |
| 옥상 주차 **요금·할인 적용** | 아쿠아리움 4시간 4,800원 할인이 **옥상에도 같게 적용되는지** 명시된 문구를 못 찾았다. 요금표는 층 구분이 없어 같을 것으로 보이나 확인 필요 |
| 옥상 RF **주말 개방 여부** | 전시 일정에 따라 운영이 달라지는지 확인 못 했다 — ☎02-6002-7130 |
| **급속 충전기가 옥상인가 B3 라이브존인가** | 코엑스 공식은 "옥상 RF 급속 6대", 2차 데이터는 "지하 3층 라이브존 퍼플01~08 기둥". **둘 다 해피차저 6대**라 같은 설비를 다르게 적었을 가능성 → 앱으로 확인 |
| **완속 47대 vs 3대** | 코엑스 공식 47대 / 2차 플랫폼 3대. 등록 단위 차이로 보이나 확정 못 함. **같은 플랫폼의 코엑스 주차요금이 공식과 달라 신뢰도 낮음** |
| **아쿠아리움 4,800원 할인이 옥상에도 적용되는지** | 요금표에 층 구분이 없고 차량번호 등록 방식이라 적용될 것으로 보이나(B등급 추론) **명시 문구 없음** — 정산기에서 확인 |
| 코엑스 **전기차 주차 감면** | **없다**(공식 요금표 확인). 감면은 장애인·국가유공자 50%뿐 — 미확인이 아니라 **확인된 부재** |
| 봉은사역·삼성역 도보 시간 | 2차 출처만 있음 |
| 입장료 | 프로모션·제휴가 수시 변동이라 미기재 — 방문 전 공식 확인 |
| **인어 공연 착석 시각** | **공식 안내에 문구 없음.** "30분 전 착석"은 2026-09-20 **1회 관찰(C)**. 회차·요일별로 다를 수 있음 |
| 인어 공연 **소요 시간** | 공식에 없음 (가오리·물범은 각 10분 명시) |
