## 2. 어디에 대는가 — 코엑스 공식 주차지도를 직접 읽었다

### 🔴 먼저 정정 — 초판에 옮겨 적은 "블루존 18~20구역"은 공식 지도와 맞지 않는다

씨라이프 FAQ 원문은 이렇다.
> "아쿠아리움에서 가까운 주차장은 **코엑스몰 북문 주차장**이며 **지하2층 블루존 18~20구역**입니다."

그런데 **코엑스 공식 B2 주차지도**(`coex.co.kr/wp-content/uploads/2026/03/map-store-b2.png`, 6871×4765)를 받아 읽으니 다르다.

| 지도상 색 | 구역 번호 | 위치 |
|---|---|---|
| **초록** | **15~25** | 트레이드타워 · 별마당 도서관 (서쪽, 삼성역 방향) |
| 보라 | 26~39 | 도심공항타워 · 전시컨벤션센터 중앙 |
| **파랑(블루)** | **40~65** | **그랜드볼룸 · 영화관 · 아쿠아리움** (동쪽, 봉은사역 방향) |
| 주황 | 48~65 (하단) | 아셈타워 전용 |

**18~20은 초록 구역이고 아쿠아리움 반대편이다.** FAQ의 "블루존 18~20"은 옛 체계이거나 오기로 보인다.
**색(블루존)은 맞고 번호가 틀렸다.** 지도를 따른다. <A등급 — 공식 지도>

### 아쿠아리움에 가장 가까운 자리

> **B2 블루존 52G ~ 60G.** 바로 앞이 **P7 에스컬레이터**이고, 옆에 "영화관 전용 출입구"가 있다.

지도에 그 구역 위쪽으로 **「그랜드볼룸 | 영화관 | 아쿠아리움」**이라고 적혀 있다.

### 🔴 5판 정정 ② — 아쿠아리움은 **B1**이다. 같은 층이 아니다

5판에 나는 *"아쿠아리움도 B2라 같은 층, 수평 이동만 하면 된다"*고 썼다. **틀렸다.**
공식 B2 주차지도 **범례**를 확대해 읽으니 P5·P7의 연결 표기가 이렇다.

> P7 — `1F` 그랜드볼룸 / **`B1` 영화관 | 아쿠아리움** / 스타필드 코엑스몰
> P5 — `1F` 전시컨벤션센터 로비 / **`B1` 영화관 | 아쿠아리움** / 스타필드 코엑스몰

**B2에 대고 → P7에서 한 층 올라가 B1.** 층 표시를 안 읽고 "같은 층"이라고 단정한 것이다. <A등급 — 공식 지도 범례>

### 🔴 그리고 P7에는 **엘리베이터가 없다** — 유아차가 있으면 P5

같은 범례의 아이콘을 하나씩 확인했다.

| 출입구 | 에스컬레이터 | 엘리베이터 | 유아차 |
|---|---|---|---|
| **P7** (가장 가까움) | **B4~1F** | **없음** | **곤란** |
| **P5** | B4~3F | **B4~1F 있음** | **가능** |
| P6 (아셈타워) | — | B4~1F | 코엑스몰 이동 불가 |

**유아차를 가져가면 P7이 아니라 P5 쪽에 댄다.** P5는 B2 지도상 44~51번 열 근처로, 52G~60G보다 조금 멀지만 엘리베이터가 있다.
유아차 없이 3세를 안고 간다면 **P7이 가장 짧다**. <A등급 — 공식 지도 범례 아이콘>

### B2 엘리베이터/출입구 7곳 — 아쿠아리움은 P5·P7뿐

| P | 색 | 연결 시설 | 층 |
|---|---|---|---|
| P1 | 초록 | 트레이드타워 · 스타필드 · 코엑스아티움 | B2~B1 |
| P2 | 초록 | 별마당 도서관 · 스타필드 · 트레이드타워 | B2~B1, B2~1F |
| P3 | 보라 | 전시컨벤션센터 로비 · 스타필드 | B2~1F |
| **P4** | 보라 | 전시컨벤션센터 로비 · 스타필드 | **B2~RF (옥상)** |
| **P5** | 파랑 | 전시컨벤션센터 로비 · **영화관·아쿠아리움** · 스타필드 | B4~3F, B4~1F |
| P6 | 주황 | 아셈타워 **전용** (B1 스타필드로 이동 불가) | B4~1F |
| **P7** | 파랑 | 그랜드볼룸 · **영화관·아쿠아리움** · 스타필드 | B4~1F |

**「아쿠아리움」이 적힌 건 P5와 P7 둘뿐이다.**

### 출구 GATE — 나갈 때 쓰는 번호

공식 B2 지도의 노란 `≪ 출구 / Way Out` 표기다. **들어갈 때 쓰는 이름이 아니다**(§2-C).

| 출구 GATE | 도로 |
|---|---|
| GATE 1 · 2 · 3 | **영동대로** |
| **GATE 4** | **봉은사로** ← 우리 자리에서 가장 가깝다 |
| GATE 5 | 아셈로 |

- 아쿠아리움 내부 B2 지도의 **`P` 주차등록(Parking Registration)** 아이콘 — 무지개 라운지(2) 위쪽. **할인 등록 키오스크는 여기다.**

## 2-C. 입구 — 도로에서 자리까지 (6판 신규)

> 물어보신 부분이다. **"코엑스 주차장 입구도 중요하더라."** 맞다. 그리고 여기서 5판의 오류가 하나 나왔다.

### 🔴 코엑스에는 번호가 다른 두 체계가 있고, 나는 그걸 섞어 썼다

5판에서 나는 "GATE 4(봉은사로)로 **진입**하라"고 썼다. 공식 자료를 각각 원문으로 받아 보니 이렇다.

| 체계 | 무엇인가 | 표기 |
|---|---|---|
| **진입로(들어가는 곳)** | 코엑스 공식 「주차장 입구 안내」 지도 | **이름**으로만 부른다 — 서문 / 동문 / 북문 / 트레이드타워 / 아셈타워 GATE. **번호가 없다** |
| **출구(나가는 곳)** | 코엑스 공식 B2 주차지도 범례의 `≪ 출구 / Way Out` | **번호**로 부른다 — GATE 1·2·3(영동대로) / GATE 4(봉은사로) / GATE 5(아셈로) |

**GATE 1~5는 나가는 문이다.** 들어갈 때 내비에 찍을 "GATE 4"는 없다. <A등급 — 코엑스 공식 지도 2종>

씨라이프가 말하는 "북문(GATE 4)"은 **같은 봉은사로 쪽 램프를 출구 번호로 부른 것**이다. 도로는 맞고 부르는 이름이 달랐다.

### 진입 GATE 5개 — 공식 「주차장 입구 안내」 지도

| 진입 GATE | 접한 도로·랜드마크 | 어디로 들어가나 |
|---|---|---|
| **코엑스 서문 GATE** | 봉은사 사거리 쪽 · 세븐럭 카지노 앞 | **옥상(RF) + 지하 전부** |
| **코엑스 북문 GATE** | **봉은사로 — 봉은사 건너편** | 지하 |
| 코엑스 동문 GATE | 라이브플라자 앞 | 지하 (전시장 방문용) |
| 트레이드 타워 GATE | 삼성역 쪽 | 지하 (트레이드타워용) |
| 아셈타워 GATE | 아셈플라자 앞 | 지하 (**아셈타워 전용**) |

**⚠️ 아셈타워 GATE는 쓰면 안 된다.** B2 지도 범례 원문: *"본 출입구는 아셈타워 전용으로 **B1 스타필드 코엑스몰로 이동 불가**하오니 다른 입구 이용바랍니다."* <A등급>

### 목적지별 공식 답 — 코엑스가 직접 알려준다

코엑스 주차안내 페이지의 「주차장 입구 안내」는 **층별·목적지별로 다른 지도**를 띄운다. 그 지도 파일을 직접 받아 읽었다.

| 고르면 | 공식 지도가 강조하는 진입 GATE |
|---|---|
| **옥상(RF)** | **서문 GATE 하나뿐** |
| **B2** = **코엑스몰** | **5개 전부** (서문·북문·동문·트레이드타워·아셈타워) |

즉 **B2는 "아무 데로 들어와도 된다"**가 코엑스의 공식 입장이다. 옥상만 서문으로 한정된다. <A등급>
(5판에 B등급으로 적었던 "옥상은 서문 GATE 진입 후 지상 3층"은 **이걸로 A등급이 됐다**.)

### 그래서 아쿠아리움은 어디로 들어가나 — **북문 GATE**

공식이 5개를 다 열어놨으니 결정은 **"어느 문이 아쿠아리움에 가장 가까운가"**다. 근거 3개가 한 방향을 가리킨다.

1. **씨라이프 공식**: *"아쿠아리움에서 가까운 주차장은 **코엑스몰 북문 주차장**"*
2. **씨라이프 공식 단체 안내**: *"코엑스북문 4번 GATE(**봉은사 반대편**)"* / *"코엑스 북문(GATE 4) 하차 시 **직원이 아쿠아리움까지 인솔**"*
3. **코엑스 공식 B2 지도**: 북문 바로 안쪽이 **그랜드볼룸 | 영화관 | 아쿠아리움** 구역이고, 그 앞이 **P7**이다

세 개가 같은 지점을 말한다. → **북문 GATE → B2 → 52G~60G → P7.** <A등급>

### 하남 미사에서 오는 길 — 어디서 북문으로 붙나

코엑스 공식 「오시는 길」에서 북문으로 가는 경로는 둘이다. <A등급 — 원문>

> **영동대교 방면 1**: 영동대교를 건너서 경기고 및 청담역 사거리 직진 → **코엑스사거리에서 우회전, 봉은사사거리에서 유턴하여 북문 GATE**를 통하여 코엑스 지하주차장 진입.
> **강남고속터미널 방면 2**: 교보타워 사거리에서 직진하여 라마다 호텔을 지나 직진 → **봉은사사거리에서 우회전 후 100m 직진하여 우측에 있는 북문 GATE**를 통하여 코엑스 지하주차장으로 진입.

미사에서는 올림픽대로 → 영동대교가 자연스럽다. 즉 **위쪽(영동대교 방면 1)**이 우리 경로다.
**핵심은 "봉은사사거리에서 유턴"이다.** 봉은사로에 코엑스 쪽으로 붙여야 우회전으로 북문에 들어간다. 이걸 모르면 코엑스를 한 바퀴 돌게 된다 — **어제 힘들었던 게 이것일 수 있다.**

> 내비에 찍을 것: **"코엑스 북문"**. "코엑스"만 찍으면 대표 주소(영동대로 513)로 안내돼 **동문·트레이드타워 쪽**으로 갈 수 있다. <D등급 — 내비 동작은 앱마다 달라 확인 못 했다. 출발 전에 목적지 검색 결과를 한 번 보시는 게 확실하다>

## 2-B. 지하 B2 vs 옥상 RF — 물어보신 비교

코엑스 공식 **RF(옥상) 주차지도**도 받아 읽었다.

| 항목 | **지하 B2 블루존** | **옥상 RF** |
|---|---|---|

**결론: 아쿠아리움만 갈 거면 지하 B2 블루존이 맞다.** 이미 제대로 대셨다.
옥상으로 바꾸면 **아쿠아리움까지 오히려 멀어진다** — B1까지 내려가 스타필드를 가로질러야 한다.

**옥상이 쓸모 있는 유일한 경우: 지하가 만차일 때.**
진입 동선이 **지하 램프가 아니라 서문에서 지상으로 올라가는 길**이라 지하 대기 줄과 섞이지 않는다. 다만 구획이 적어 옥상도 금방 찬다.

→ **어제 힘들었던 게 "진입 대기"였다면, 답은 층을 바꾸는 게 아니라 ①진입을 북문 GATE로 고정하고 ②출발 전 만차 예측을 보는 것**이다. (→ §2-C)

## 8. 확인하지 못한 것

| 항목 | 상태 |
|---|---|
| 주차 할인 **4,800원 vs 6,000원** | 씨라이프 **공식 FAQ는 4,800원**. 일부 2차 출처가 6,000원이라 함 → **공식 채택** |
| 코엑스 주차장 **총 대수** | 공식 페이지에 없음 |
| 주말 **구체적 만차 시각** | 실시간 데이터라 사전 고정값 없음 — **당일 확인이 정답** |
| ~~"북문"이 GATE 몇 번인지~~ | **6판에서 해결.** 진입로는 **이름**(서문·북문·동문·트레이드타워·아셈타워), 출구는 **번호**(GATE 1~5). 씨라이프의 "북문(GATE 4)"은 같은 봉은사로 램프다 → §2-C |
| **GBB 12,000원의 단위** | 공식 원문이 "먹이 포함 12,000원"이라고만 쓰고 **1인/보트 구분이 없다.** 4인이면 12,000 vs 48,000으로 4배 차이 → **현장 또는 ☎02-700-7200** |
| **GBB 예약만 걸고 나중에 탈 수 있는지** | 원문은 "체험존에서 현장 예약만 가능"까지만 말한다. C+안의 28분 대기 리스크가 여기 달려 있다 |
| **GBB 보트 1대 정원 / 보호자 동반 인원** | 공식에 없음. 4인 가족이 한 번에 타는지 미확인 |
| **VR 체험존의 정확한 위치** | "⑥ 해양 디스커버리 인접"은 **현장 사진 1장 근거(C등급)**. 공식 페이지는 주소만 적고 구역을 안 밝힌다 |
| 내비에서 **"코엑스 북문"** 검색 결과 | 앱마다 다를 수 있어 확인 못 함 — 출발 전에 한 번 찍어보시는 게 확실 |
| 씨라이프 FAQ의 **"블루존 18~20구역"** | 공식 지도와 불일치(18~20은 초록). 색은 맞고 번호가 틀린 것으로 보이나 **확정은 02-700-7200 문의** |
| 옥상 주차 **대수** | 공식 수치 없음. 지도상 적다는 것만 확인 |
| 봉은사역·삼성역 도보 시간 | 2차 출처만 있음 |
| 입장료 | 프로모션·제휴가 수시 변동이라 미기재 — 방문 전 공식 확인 |
| **인어 공연 착석 시각** | **공식 안내에 문구 없음.** "30분 전 착석"은 2026-09-20 **1회 관찰(C)**. 회차·요일별로 다를 수 있음 |
| 인어 공연 **소요 시간** | 공식에 없음 (가오리·물범은 각 10분 명시) |
| 가오리 공연 후 **자리 유지 가능 여부** | 인어 14:30 → 가오리 15:30 사이 퇴장 요구가 있는지 미확인 |
