## 0. 열 줄 요약
1. 브릿지론은 "땅 잔금 대출"이다. 시행사는 계약금 10%만 내고, 잔금 90%와 취득세·이자·수수료까지 빌린다. 담보는 인허가도 안 난 맨땅 하나.
2. 그래서 은행이 못 들어오고 저축은행·캐피탈·새마을금고·중소 증권사가 연 10~20%에 빌려줬다. 2022년 하반기엔 법정최고 20%, 수수료 합치면 50%인 곳도 나왔다.
3. 2019~22년 이 대출이 폭증했다. 새마을금고 관리형토지신탁 대출 90배, 저축은행 브릿지는 자기자본의 128%(2023.6).
4. 땅값이 같이 뛰었다. 2021년 전국 지가 4.17%, 공공택지 경쟁률 214:1. 서울 분양가의 65%가 땅값이다.
5. 2022년 하반기부터 본PF 대주가 사라졌다. 저축은행 브릿지의 본PF 전환율 5% 미만(2023 상반기). 못 넘어간 브릿지는 만기연장·이자 유보로 버텼다.
6. 저축은행은 브릿지를 "토지담보대출"이라는 일반대출로 분류해 PF 규제(총대출 20% 한도, 충당금 10%)를 피했다. 2024.1.1부터 PF로 재분류됐다.
7. 그 토지담보대출 연체율이 32.43%(2025.9, 중소금융 12.4조)다. 브릿지론 연체율은 10.14%(2024.3, 증권 20.26%·저축 14.00%), 본PF는 2.57%.
8. 사업성평가 1차(2024.6) 유의·부실우려 21조 중 브릿지 4조 + 토담대 12.9조 = 16.9조(80%). 본PF는 4.1조. **부실의 8할이 착공 전 땅이다.**
9. 땅은 경공매로도 안 빠진다. 매각가율 72.3% → 58.2%. 2008년 저축은행 브릿지의 5년 누적 회수율은 0.5% 미만이었다.
10. 공공택지도 같다. LH 택지 해약 2022년 383억 → 2024년 2조7,052억, 누적 4조3,486억(2만1,612가구). 계약금 10%를 포기하고 나갔다.

## 1. 브릿지론이 정확히 무엇인가

### 정의
시행사가 토지 매매계약 뒤 **잔금을 치르기 위해** 받는 단기(6개월~1년, 연장 포함 1~2년) 토지담보대출. 인허가·시공사·본PF가 확정되기 전 단계라 "다리(bridge)"다. 본PF가 실행되면 본PF 대출금으로 브릿지 원리금을 갚는다(시사온: "브릿지론 채무가 본PF로 넘어간다").

### 무엇을 빌리나 `[통상, 계약별 상이]`
| 항목 | 내용 |
|---|---|
| 토지 잔금 | 매매대금의 90%(계약금 10%는 시행사 자기자본) |
| 취득세 | 토지 4%(+지방교육세 0.4%·농특세 0.2% = 4.6%). 수도권 과밀억제권역 5년 미만 법인은 중과 |
| 초기 사업비 | 설계·인허가 용역, 신탁보수, 감정평가 |
| 이자 유보 | 만기까지 이자를 대출금에서 미리 떼어 유보계좌에 넣음. **대주는 실행일에 1년 이자를 이미 확보** |
| 수수료 | 취급·주선·자문 수수료 선취(2025.1 모범규준 전까지 항목 최대 32개) |

→ 3,000억짜리 땅이면 브릿지론은 3,300~3,600억이 된다. 사례: 더팰리스73 부지 매입 3,500억(2020) → 브릿지 3,650억(2021) → 4,050억(2022, A 3,300·B 550·C 200). 땅은 그대로인데 대출이 550억 늘었다. 이자·수수료가 원금이 된 것이다.

### 담보와 신용보강
- 토지를 신탁사에 담보신탁하고 대주가 1순위 우선수익권을 잡는다. 트랜치별로 순위를 나눈다.
- 시행사 대표 연대보증·시행사 주식 질권 `[통상]`. 시공사 신용보강은 브릿지 단계에서는 드물고, 있으면 "시공사 자금보충" 또는 "본PF 참여 확약" 형태.
- 담보인정비율은 감정가 대비 60~80% `[통상, 공식 규제 없음]`. 그런데 감정가는 "개발 후 가치"를 반영해 매입가보다 높게 나오는 경우가 많아, 실제로는 매입가의 100% 이상이 나간다(더팰리스73 사례).

### 누가 빌려주나
| 대주 | 이유 | 규모 지표 |
|---|---|---|
| 저축은행 | 고금리 선호, 예금으로 조달 | 브릿지 자기자본 대비 128%(2023.6, 적정 30~40%). PF 중 브릿지 비중 60.8%(한신평) |
| 캐피탈(여전사) | 회사채로 조달, 부동산 PF 급성장 | PF 13.8조(2020) → 23.9조(2024.6), 브릿지 비중 35%. 2024 하반기 브릿지 1.7조 감축 |
| 새마을금고 | 행안부 소관, 금융위 통계 밖 | 관리형토지신탁 대출 1,694억(2019) → 15.4조(2022) |
| 중소 증권사 | 중후순위 고수익 | 브릿지 중후순위 비중 중소형 65%(대형 34%). 브릿지 연체율 20.26%(2024.3) |
| 새마을금고·신협 등 상호금융 | 공동대출(수십 개 금고가 쪼개서) | 신독산 브릿지 1,600억에 53개 기관, 새마을금고 800억 |

## 2. 토지비가 어떻게 움직였나

### 땅값
| 연도 | 전국 지가 | 서울 | 비고 |
|---|---|---|---|
| 2021 | 4.17% | 5.31% | 정점. 세종 7.06%. 공공택지 214:1 |
| 2023 | 0.82% | - | 15년 최저 |
| 2024 | 2.15% | - | |
| 2025 | 2.25% | 4.02% | 강남 6.18%·용산 6.15%·서초 5.19%. 지방 0.82% |
| 2026 상반기 | 1.22% | 2.32% | 강남 2.99%·용산 2.88%·성동 2.69%. 지방 0.38% |

- 지가 통계는 전체 토지 평균이라 개발용지 급등을 못 잡는다. 개발용지는 2021년 정점에서 매입했고, 그 뒤 서울 땅값은 다시 올랐지만 지방은 멈췄다. **서울 브릿지는 땅값이 받쳐주고, 지방 브릿지는 땅값도 없다.** 한신평이 "비수도권·비주거 브릿지론 중심으로 추가 전이"를 경고한 이유.
- 서울은 땅값이 올라서 오히려 문제다. 감정가가 올라 경공매 대신 만기연장이 정당화된다(라우어·청담·성수·용산 브릿지가 전부 연장 중).

### 분양가 속의 땅값
- 서울 아파트 분양가 중 택지비 65.2%(건설기술연구원 2026.5). 분양가 상승분의 60% 이상이 택지비.
- 분양가 2021년 3.3㎡당 3,012만 → 2026.5 6,355만(+111%). 공사비지수는 같은 기간 +34%. 나머지는 땅값과 금융비.
- 즉 브릿지론으로 산 땅값이 분양가로 전가된다. 전가가 안 되면(분양 실패) 브릿지 부실이 된다.

### 공공택지: LH도 예외가 아니다
| 연도 | 해약 필지 | 금액 |
|---|---|---|
| 2022 | 2 | 383억 |
| 2023 | 5 | 3,749억 |
| 2024 | 25 | 2조 7,052억 |
| 2025(7월까지) | 13 | 1조 2,303억 |
| 누적 | 45필지·116만㎡(35만평) | 4조 3,486억, 2만 1,612가구 |

- 해약하면 계약금 10%는 LH에 귀속된다. 즉 건설사·시행사가 수백억 계약금을 버리고 나갔다(헤럴드 "눈물의 계약금 포기").
- 해약 조건: 6개월 이상 연체 또는 연체이자가 계약금 초과. 대주단이 해약을 요청하기도 한다.
- 미매각 택지 102.7만㎡(2022) → 133.6만㎡(2024). 연체 사업장 30곳 4,130억. 판촉(토지리턴제·무이자 할부·거치식 할부) 대상 49곳 중 11곳만 팔림(22.4%).
- 토지리턴제 = 잔금 전 일정 기간 안에 리턴권을 쓰면 계약금 포함 원금 전액 반환. 2024년 도입. **LH가 시행사의 브릿지 위험을 대신 지는 구조**다.

## 3. 브릿지론이 어떻게 부실이 됐나

### 시간표
| 시점 | 브릿지 금리 | 무슨 일 |
|---|---|---|
| 2020.5~2021.8 | 8~9% | 기준금리 0.5%. 브릿지 급증, 땅값 정점 |
| 2022.7 | 5.69%(사례) → 연장 시 18% 제시, 13% 타결 | 금리 인상 본격화 |
| 2022.10 | 법정최고 20%, ABCP 15%대 | 레고랜드. 본PF 대주 소멸 |
| 2023 상반기 | 올인코스트 50% 사업장 등장 | 저축은행 브릿지 → 본PF 전환율 5% 미만. 자기자본 대비 브릿지 128% |
| 2023.11 | - | 저축은행 브릿지·토담대 PF 재분류 결정(2024.1.1 시행). 요주의 이하 여신비율 41%(2023.6) |
| 2024.3 | - | 브릿지 연체율 10.14%(증권 20.26%·저축 14.00%), 저축은행 토담대 20.18%. 브릿지 = PF 대출 134.2조의 13% |
| 2024.4 | - | 저축은행 브릿지 경공매 낙찰자 대출에 PF 한도(총대출 20%) 한시 면제. 조건: 낙찰가 브릿지 총액의 85% 미만, 시행사 교체, 자기자본 10% |
| 2024.5~6 | - | 사업성평가 4단계. 1차 대상 = 연체·연체유예·만기연장 3회↑ 33.7조 |
| 2024.8 | - | 1차 결과 C·D 21조. **브릿지 4조·토담대 12.9조·본PF 4.1조** |
| 2025.9 | - | 토담대 12.4조 연체율 32.43%(2023말 29.7조에서 줄었는데 연체채권 2.1 → 4조). 경공매 매각가율 58.2%(2026.5) |
| 2025.12.22 | - | 자기자본비율 2027 5% → 2030 20%. 저축은행·상호금융은 자기자본 20% 미만 사업 대출 금지 |
| 2026.8.13 | - | 주거 사업장 자기자본 규제 2029로 유예. 본PF 정부보증 86조 |

### 왜 못 넘어가나 (본PF 전환 실패의 산식)
```
사업성 = 분양 매출 - (토지비 + 공사비 + 금융비 + 사업비)
2021 계약 시점: 분양가 A, 공사비 B, 브릿지 8%
2023 본PF 시점: 분양가 A(못 올림·미분양), 공사비 B×1.3, 브릿지 13~20% 2년 누적
→ 시행이익 0 이하 → 본PF 대주 "exit 분양률 미달" → 미실행
```
- 토지비는 이미 확정된 매몰비용이고 브릿지 이자는 매일 원금에 쌓인다. 기다릴수록 사업성은 더 나빠진다. 그런데 대주는 경공매(58%)보다 연장(장부 100%)을 택한다. **시간이 갈수록 손실은 커지고 인식은 미뤄지는 구조.**
- 인베스트조선 "가짜 본PF": 착공 없이 브릿지 대주가 본PF 명목으로 재약정. 사업성평가에서 본PF는 브릿지보다 등급이 유리하다.

### 왜 회수가 안 되나
- 담보가 맨땅이라 준공 건물이 있는 본PF보다 회수율이 낮다. 2008년 저축은행 브릿지 5년 누적 회수율 0.5% 미만(아주경제 2023.7, 신평사 인용).
- 감정가가 "개발 후 가치"였으므로 매입가 이상으로 빌려줬고, 경공매 감정가는 "현 상태 토지"라 낮게 나온다. 사례:
  - 대전 용계동 브릿지 980억(4개 트랜치) → 감정가 450억 → 14회 유찰 230억(51%)
  - 신독산 브릿지 1,600억(53개 기관) → 감정가 1,556억 → 910억(17회 이상 유찰)
  - 신갈오거리 감정가 1,288억 → 11회 유찰 900억
  - 오데뜨오드 도곡 1순위 950억 → 감정가 1,407억 → 5차 905억(64%)
- 후순위·중순위는 이 매각가에서 선순위를 빼면 0이다. 그래서 후순위 대주(중소 증권사·저축은행)는 경공매에 반대하고 연장에 찬성한다. 대주단 협약 3/4 동의 요건은 연장을 막는 장치가 아니라 "후순위가 선순위를 설득하는" 장치로 작동한다.

## 4. 저축은행의 규제 회피 경로 (토지담보대출)

| 항목 | PF(브릿지) 분류 | 일반대출(토담대) 분류 |
|---|---|---|
| 총대출 대비 한도 | 20% | 없음 |
| 요주의 이하 충당금 | 10% | 1% |
| 자기자본 요건 | 시행사 자기자본 20% 이상 사업장만 | 없음 |
| 감독 통계 | PF 익스포저 | 기업대출 |

- 2023년 11월까지 저축은행은 신규 브릿지를 "토지담보대출"로 취급해 이 세 가지를 모두 피했다. 파이낸셜뉴스 2023.11.23: "2024.1.1부터 신규 브릿지론·토담대를 PF로 재분류". 업계 반발: "모든 토담대를 일괄 PF 포함은 납득 못 해".
- 그 결과 저축은행 PF 잔액이 10.5조(2022) → 22.1조(2023)로 두 배로 "보였다". 새로 빌린 게 아니라 이름이 바뀐 것이다.
- 재분류된 토담대의 연체율이 32.43%다. 이게 브릿지의 진짜 연체율에 가깝다.
- 새마을금고의 "관리형토지신탁 대출"도 같은 기능이다. 행안부 소관이라 금융위 PF 통계에 2024년 사업성평가부터 들어왔다.

## 6. 앞으로: 브릿지에 무슨 일이 생기나

1. **9~10월 대형 브릿지 만기**: 용산 크라운 4,063억(9월), 청담 프리마 7,000억(9.22, 본PF 심의 9.17), 성수 삼표 6,400억(10.14, 대주 221곳). 셋 다 서울 핵심지라 땅값은 받쳐준다. 본PF 전환되면 "정부 보증 + 서울 땅값"으로 넘어가는 첫 사례, 안 되면 연장 5회차.
2. **자기자본 규제**: 2027년 5%는 비주거만 적용(주거는 2029). 저축은행·상호금융의 "자기자본 20% 미만 사업 대출 금지"는 사실상 브릿지론 신규 취급 금지다. 9.2 보도대로 이것도 유예되면 브릿지 구조는 그대로 남는다.
3. **정부 보증 86조의 의미**: 본PF에 HUG·주금공 보증을 붙이면 은행이 들어오고, 브릿지 대주는 원리금을 회수해 빠진다. 부실 브릿지의 출구를 국가 보증이 만들어주는 것. 문제는 "본PF가 되면 분양이 되나"이고, 그건 보증이 해결 못 한다.
4. **지방·비주거 브릿지**: 땅값도 정부 보증도 없다. 한신평이 추가 전이 가능성 캐피탈 87%·저축 53%·증권 35%를 본 곳이 여기다. 경공매 → 유찰 → 정상화펀드(자기 돈) → 장부 유지가 반복된다.

## 8. 확인 필요
- 한신평 "브릿지론 약 30조·저축은행 13조"의 기준 시점과 토담대 포함 여부. 금융위 17.4조는 정의가 좁은 숫자다. 기능적 브릿지(토담대·펀드 이관 포함) 47조 이상 계산은 `reports/PF-통계-사각지대.md`.
