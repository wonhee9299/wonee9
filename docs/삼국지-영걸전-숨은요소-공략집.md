# 삼국지 영걸전 — 숨은 요소 공략집

> KOEI, 1995. 유비를 주인공으로 하는 삼국지 SRPG 시리즈 1편.
> 이 문서는 **놓치기 쉬운 숨은 요소**(보물창고·선택지 분기·사자 이벤트·숨은 영입)에 초점을 맞춘다.
> 기준은 **원작 영걸전**이다. 팬 개조판인 *영걸전 리메이크* / *영걸전 리파인* 은 수치와 분기가 다르므로 그대로 적용하면 안 된다.

---

## 0. 먼저 알아둘 규칙

- **패배 조건**: 유비의 병력이 0 · 유비의 사기가 0 · 제한 턴 초과. 셋 중 하나만 걸려도 패배다.
- **아이템 소지 한도**: 한 무장당 **8개**. 종류 구분이 없다. 후반에 회복약을 쟁여두면 정작 보물을 못 든다.
- **보물창고 / 군량고**는 일반 지형보다 **이동력을 더 먹는다.** "한 칸이 모자라서 못 들어가는" 사고가 이 게임 최대의 손실 원인이다. 보물이 있는 맵은 1턴째부터 경로를 역산해서 움직여라.
- 보물창고에는 **그 시점 상점에서 살 수 없는 물건**이 들어 있다. 시세로 비교하지 말고 무조건 회수한다.
- 전투가 끝나면 그 맵은 다시 갈 수 없다. **미회수 = 영구 손실.**

## 1. 숨은 요소는 4가지 경로로 들어온다

| 경로 | 정체 | 놓치면 |
|---|---|---|
| **보물창고 / 군량고** | 맵 위 칸을 밟아 회수 | 영구 손실 |
| **선택지 분기** | 전투 전후 대화에서 고르는 갈림길 | 스토리·아이템·동료가 통째로 바뀜 |
| **사자(설득) 이벤트** | 특정 무장을 사자로 보냄 | 아이템 + 전투 스킵을 동시에 놓침 |
| **일기토** | 특정 무장끼리 인접 시 발생 | 연동 아이템을 놓침 |

## 2. 최대 분기 — 맥성의 전투

**이 게임의 스토리는 맥성에서 갈린다.** 여기서 결정되는 것:

- 관우의 생사
- 장비의 생사
- 관평 · 주창 · 왕보 · 요화 · 조루의 생존 여부
- 장료 영입 가능 여부
- 엔딩

### 관우 생존 조건

둘 중 **하나만** 만족하면 된다.

1. **적 전멸**, 또는
2. **관우를 맵 서쪽 끝까지 탈출**시킨다.

관우가 **퇴각당하면 그 자리에서 사망**한다. 병력이 깎이는 걸 버티는 게 아니라, 처음부터 탈출을 목표로 움직이는 편이 안전하다.

> **준비**: 관우는 앞선 여러 전투에 결장하기 때문에 레벨과 장비가 뒤처져 있기 십상이다. 맥성 이전에 관우·관평에게 경험치와 아이템을 몰아줘라. **적토마(이동 +3)를 관우에게 주면 탈출 난이도가 크게 내려간다.**

### 맥성 이후의 갈래

```
맥성의 전투
├─ 관우 생존 ──┬─ 오와 동맹  → 손자의 병법서 획득 · 서릉 전투 스킵 · 즉시 제4장
│              └─ 오와 결전  → 장비가 전투 직전 합류 · 서릉 전투 진행
└─ 관우 사망 ──┬─ 오와 동맹  → 손자의 병법서 획득 · 서릉 전투 스킵 · 즉시 제4장
               └─ 오와 결전  → 장비 암살 · 서릉 전투 진행
```

- **오와의 동맹은 관우의 생사와 무관하게 선택할 수 있고, 선택하면 손자의 병법서(방어 +22%)를 받는다.** 게임 내 최상급 방어 아이템이다.
- 오와 화목하는 선택지 계열에서는 병법서를 받고 해당 전투가 스킵된다. 화목하지 않으면 이릉 전투로 이어진다.
- **관우를 살리면 장비도 자연히 산다.** 관우 생존 이후에는 무슨 선택을 하든 전투에서 이기기만 하면 해피엔딩이다.

## 3. 사자(설득) 이벤트 — 아이템 + 전투 스킵

숨은 요소 중 **가성비가 가장 높다.** 아이템을 받으면서 전투 하나를 통째로 건너뛴다.

### 서주 구원전 · 소패

선택지: **조조와 싸운다 / 조조와 휴전을 맺는다**

- **휴전**을 고르면 장비가 사신으로 가고, 도겸에게 **자웅일대검**을 받는다.

### 유장 항복 (익주 공략전)

- **마초를 사자로 보내 유장을 설득**하면 → **조황비전(이동 +1)** 획득 + **성도의 전투 스킵**.
- 반대로 성도의 전투를 진행하면, **유장을 제외한 이름 있는 적장들을 유비가 설득해 아군으로 만들 수 있다.**

> 아이템·시간을 원하면 설득, 동료 머릿수를 원하면 전투. 둘 다는 안 된다.

---

## 4. 방통 생사 분기 — 낙성의 전투 (낙봉파)

- 방통이 **10턴까지 살아 있으면 생존**한다. 10턴 안에 퇴각하면 역사대로 사망.
- 방통은 합류 직후 첫 전투가 곧 생사 분기라, 한 턴 써보고 그대로 죽는 경우가 흔하다.
- **살려두면 이득이 크다.** 후반 야전에서 광역 책략 *폭풍*으로 판을 정리할 수 있고, **제4장 별동대의 총대장**이 된다. (방통이 죽었다면 조운이 총대장을 맡는다.)

**요령**: 방통을 전진시키지 말고 아군 뒤쪽에 붙여 10턴을 흘려보내는 것이 정석이다.

---

## 5. 제4장 별동대 — 파견해야만 열리는 전투

**별동대를 파견하면 진창·장안 전투가 추가되고, 대신 낙양 전투가 확실히 스킵된다.**

- **총대장**: 방통(생존 시) / 조운(방통 사망 시)
- **진창의 전투** — 위연 vs 학소 일기토. 승리 조건은 학소 격파. 위연이 계속 밀리다가 결정적 순간에 학소의 지병이 도져 끝난다.
- 장안의 전투는 **진창을 클리어해야** 열린다.

### 별동대에서만 나오는 것

- **육도(방어 +15%)**, **삼략(방어 +15%)** — 별동대 첫 전투인 진창에서 획득
- **궁술지침서** — 진창
- **이민족 전원 영입** — 진창에서 **마초가 이민족 고창 · 장획 · 정덕 중 한 명이라도 접촉**하면 이민족이 전부 아군이 된다

## 7. 병과 — 숨은 최적해는 주술사

- **전직 타이밍**: 레벨 **15**, 레벨 **30**
- 보병: 단병 → 장병 → 전차대
- 기병: 경기병 → 중기병 → 친위대
- 궁병: 궁병 → 연노병 → 발석차
- 적병: 산적 → 흉적 → 의적

### 보조계 (수송대 · 군악대 · 주술사)

- **상성이 아예 없다.** 상성으로 얻어맞지 않는다는 뜻이다.
- 1레벨 기본 병력은 300으로 동일하지만, 레벨업당 **수송대 · 군악대 +40 / 주술사 +50**. 주술사가 몸도 조금 더 튼튼하다.
- **주술사는 후반에 최강 사기 책략 *낙뢰*를 배운다.** 한 부대만 있어도 낙뢰를 난사할 수 있어 사실상 밸런스 붕괴다.

> 정공법으로 클리어했다면, 두 번째 회차에서는 **둔갑천서로 주술사를 만들어보는 것**이 이 게임의 숨은 재미다.

## 8. 숨은 영입 무장

| 무장 | 조건 |
|---|---|
| **장료** | **관우 생존** 상태에서 허창 전투 대화 이벤트로 항복 |
| **관평 · 주창 · 왕보 · 요화 · 조루** | **관우 생존** 상태로 완의 전투 2 종료 → 허창부터 합류 |
| **서서** | 남양 전투에서 우군으로 활약 후 이탈. **장안 / 낙양 전투에서 아군과 인접**시키면 우군으로 재합류 |
| **감녕 · 능통 · 서성 · 정봉** | 제4장 형주탈환, **신야 또는 남사 전투** 종료 후 레벨 40 전후로 합류 |
| **고창 · 장획 · 정덕 (이민족)** | 별동대 진창 전투에서 **마초가 한 명이라도 접촉** |
| **이명** | 태산 전투를 선택 |
| **조하** | 팽성 전투를 선택 |
| **동량** | 하구 전투를 선택 |

> 태산 / 팽성 / 하구는 **어느 쪽을 고르냐에 따라 동료가 달라지는 선택지**다. 한 회차에서 셋을 다 모을 수는 없다.

## 9. 일기토

특정 무장이 특정 적과 인접하면 발생한다. 확인된 것들:

| 전투 | 대진 |
|---|---|
| 북해의 전투 | 조운 vs 관해 |
| 서주의 전투 1 | 관우 vs 우금 |
| 소패의 전투 | 장비 vs 하후연 |
| 양양의 전투 1 | 조운 vs 장윤 |
| 강하의 전투 | 조운 vs 장무 → **적로 획득** |
| 진창의 전투 (별동대) | 위연 vs 학소 |

> **강하의 조운 vs 장무는 반드시 챙겨라.** 이동 +2짜리 적로가 여기서만 나온다.

## 10. 주의 — 알려진 진행 불가 버그

- 치트/숨겨진 요소를 사용한 뒤 **남양의 전투에서 유비로 조인을 퇴각시키면 게임이 더 이상 진행되지 않는다.** 해당 전투에서 조인 처리는 다른 무장에게 맡기는 편이 안전하다.

## 11. 회차 목표: 1599

커뮤니티의 대표적인 야리코미(극한 플레이) 목표.

> **최종전인 업의 전투 3연전에 출전할 최후의 15인을 전원 레벨 99로 육성한다.**

- **청랑서 · 고취구는 1599 플레이의 필수 아이템**이다. 경험치를 몰아주기 위해 부대를 보조계로 갈아끼우는 데 쓴다.
- 그래서 이 두 아이템이 나오는 **정군산 · 양양2 · 여남 · 공안**은 1599를 노린다면 절대 스킵 불가다.

## 12. 한 회차 체크리스트

**절대 놓치면 안 되는 순서**

1. 서주 구원전 — **휴전 선택 → 자웅일대검**
2. 하비 — 보물창고 **적토마 + 방천화극**
3. 광릉 — 보물창고 **칠성검**
4. 여남 · 공안 — **고취구**
5. 강하 — 조운 vs 장무 일기토 → **적로**
6. 양양 1 — **의천검** / 양양 2 — **마술지침서 · 청랑서**
7. 장사 — **영걸검**
8. 낙성 — **방통 10턴 생존**
9. 정군산 — **청랑서**
10. 가맹관 — **원군보고**
11. 익주 — **마초로 유장 설득 → 조황비전**
12. 와구관 2 — **중간 섬의 칙명서**
13. **맥성 — 관우 생존 (적 전멸 또는 서쪽 탈출)**
14. 오와 동맹 → **손자의 병법서**
15. 제4장 — **별동대 파견** → 진창에서 **육도 · 삼략**, 마초로 **이민족 영입**
16. 허창 2 — **옥새** / 허창 1 — **검술 · 궁술지침서**
17. 업 1 — **패자검**
