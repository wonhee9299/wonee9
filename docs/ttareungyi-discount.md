# 따릉이 싸게 타는 법 (2026-09 기준)

## 요금표 (정가)

| 이용권 | 1시간 | 2시간 |
|---|---|---|
| 일일권 | 1,000 | 2,000 |
| 7일권 | 3,000 | 4,000 |
| 30일권 | 5,000 | 7,000 |
| 180일권 | 15,000 | 20,000 |
| 365일권 | 30,000 | 40,000 |

초과 시 30분당 1,000원.

## 지금 실제로 되는 할인

1. 자전거·PM 교통안전교육 수료 → 1년간 정기권 15%, 일일권 30% 감면. 무료, 토요일 2시간, 만 13세 이상. 2026년은 12/12까지 남은 회차 있음. 신청: 서울시 평생학습포털(sll.seoul.go.kr)에서 "자전거 교육" 검색. 365일 1시간권 기준 30,000 → 25,500원.
2. 마일리지로 이용권 구매: 365일권 이용자가 버스·지하철과 30분 내 환승 시 회당 100M(일 200M, 연 15,000M). 평일 출퇴근 시간 과다거치소 대여·과소거치소 반납 시 회당 100M(월 5,000M).
3. 손목닥터9988 앱 걷기 포인트, 현대백화점 H.point로 따릉이 이용권 결제 가능.

## 지금은 안 되거나 확인 안 되는 것

- 기후동행카드 따릉이 옵션(+3,000원): 30일권 충전 8/31 종료, 9/29까지만 이용. 후임인 기후동행패스(모두의카드)의 따릉이 월권 할인은 "연내 순차 적용 예정"이라 아직 없음.
- 제로페이 일일권 50%·정기권 30%: 2019~2020년 한시 행사. 2026년 진행 여부 확인 안 됨. 앱 결제창에서 제로페이 선택 시 할인가가 뜨는지만 확인.
- 카드사 제휴 청구할인, 다둥이 행복카드 할인: 2026년 기준 확인된 것 없음.

## 결론

매일 타면 365일 1시간권(30,000원)이 기본이고, 교육 한 번 듣고 15% 빼서 25,500원에 사는 게 현재 최저가다. 여기에 환승·재배치 마일리지와 손목닥터 포인트를 얹으면 다음 해 연장 비용을 더 줄일 수 있다.
