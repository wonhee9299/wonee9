# 릴스 제작 워크플로 (7단계)

새 작업을 시작할 때는 아래 순서를 건너뛰지 않는다.
편집본을 먼저 만들고 나중에 콘티를 맞추는 역순은 금지한다.

## 1. 대상 소재 특정
사용자가 말하는 영상/사진을 **먼저 정확히 찾는다.** 파일명·촬영일·구간을 확인해
"이 파일이 맞는지" 사용자에게 한 줄로 확인받는다.

## 2. 원본 시간순 분석
원본을 **시간순으로** 훑어 전체 흐름을 파악한다. 주행 이벤트(개입, 우회전, 차선변경,
합류, 정체)를 타임코드와 함께 목록화한다.

## 3. 구간별 스냅샷 제시
핵심 장면을 스냅샷으로 뽑아 보여준다. 사용자가 화면을 보고 고를 수 있게 한다.

## 4. 콘티 · 자막 · 나레이션 확정
편집 전에 **짧게** 확정받는다. 이 단계에서 훅(첫 1~2초 자막/제목)을 반드시 정한다.
구조 기본값: 비용·숫자·의문 → 실제 화면 → 직접 확인 → 결론·질문

## 5. 편집본 제작
- 세로 릴스 폼
- 원본 구도 유지 + 위아래 자막 공간 활용
- 자막·나레이션 타이밍 싱크 확인 (어긋나면 재렌더)
- BGM 유무는 사용자 지시에 따름 (최근 선호: BGM 없음 + 남자 나레이션 Zippy / Airy Studio)
- 정지화면 나열 금지, 주행 영상 중심

## 6. 전달
**모바일에서 다운로드 가능한 링크** 또는 **NAS 최종본** 경로를 제공한다.

## 7. 게시 (사용자가 "올려"/"게시"라고 말한 경우에만)
Instagram `wonhee929` 로 업로드한 뒤 아래를 **모두** 확인한다.

- [ ] 게시 URL 확보
- [ ] 프로필 그리드 커버 정상 표시
- [ ] 첫 댓글 게시 완료
- [ ] AI 썸네일을 썼다면 **AI 레이블을 게시 전에** 켰는지 확인
- [ ] `docs/reels/EPISODES.md` 에 기록 추가

## 게시 전 게이트

영상 제작 착수 전 `ai-video-studio/` 의 필독 3개 문서를 읽었는지 확인한다.
(`VIDEO_PRODUCTION_MASTER_RULES.md`, `MANDATORY_VIDEO_PRODUCTION_CHARTER.md`,
`INSTAGRAM_REELS_PRODUCTION_GATE.md`)

개인정보 마스킹 확인: 얼굴 / 개인 위치 / 번호판 / 지도 / GPS / VIN.
사용자가 이번 작업에 한해 명시적으로 허용한 항목만 예외.
