# 폰에서 PC로 명령하기 (Remote Control)

## 왜 이 구성인가

인스타 게시, 영상 편집, NAS 접근은 **로그인 세션과 원본 파일이 있는 PC에서만** 된다.
클라우드 세션(claude.ai/code, 앱에서 새 세션 시작)은 매번 빈 컨테이너라
로그인된 브라우저도, `C:\Users\...\outputs\` 원본도, NAS도 없다.

Remote Control 은 **PC에서 Claude Code 를 돌리고 폰에서 그 세션에 명령**하는 방식이다.
실행은 PC에서 되므로 로그인 세션·파일·MCP 설정이 그대로 살아 있다.
코덱스가 인스타에 바로 올릴 수 있었던 것도 같은 이유다 — 실행 위치가 PC였다.

## 요구 사항

- Pro / Max / Team / Enterprise 플랜 (API 키로는 안 됨)
- PC에서 `claude` 실행 후 `/login` 으로 claude.ai 로그인
- 폰: Claude 앱 (Android / iOS) 또는 브라우저에서 claude.ai/code

## PC 설정

### 방법 A — 서버 모드 (권장, 항상 띄워두기)

여러 세션을 폰에서 골라 쓸 수 있다. 저장소 폴더에서:

```bash
claude remote-control
```

Ctrl+C 로 껐다가 다시 살릴 때:

```bash
claude remote-control            # 서버가 돌보던 세션 전부 복구
claude remote-control --continue # 시작 세션만 복구
```

### 방법 B — 대화형 세션 하나에 RC 켜기

터미널에서 직접 타이핑도 하면서 폰에서도 붙고 싶을 때:

```bash
claude --rc "릴스3"
```

이미 켜둔 세션에 붙이려면 세션 안에서 `/rc` 또는 `/remote-control`.

### 항상 자동으로 켜기

PC의 Claude Code 안에서 `/config` → **Enable Remote Control for all sessions** 를 켠다.
데스크톱 앱은 **Settings > Claude Code > Enable remote control by default**.
이걸 켜두면 PC에서 Claude Code 를 띄울 때마다 폰에서 바로 잡힌다.

## 폰에서 붙기

1. Claude 앱 → 세션 목록에서 PC 세션 선택 (이름은 `--rc "릴스3"` 처럼 지정한 값,
   안 지정하면 `호스트명-랜덤단어` 형태)
2. 또는 PC 터미널의 `/rc` 상태 패널에 나오는 **QR 코드를 폰으로 스캔**하면 앱에서 바로 열린다
3. 세션 URL 을 폰으로 보내 열어도 된다

붙은 뒤에는 폰에서 타이핑한 명령이 **PC에서 실행**된다. 터미널·폰·브라우저에서
동시에 같은 대화를 이어갈 수 있다.

## 주의

- **PC가 켜져 있고 `claude` 프로세스가 살아 있어야 한다.** 절전/종료되면 연결이 끊긴다.
  자주 쓸 거면 PC 절전을 끄거나, 작업 시작 전에 원격으로 깨울 수단을 마련해 둔다.
- 다른 기기에서 같은 세션을 가져가면(takeover) 이전 기기의 연결이 끊긴다.
  알림에 이유가 표시되므로 읽고 나서 `/remote-control` 로 되찾을지 결정한다.
- 클라우드 세션(새로 시작한 웹/앱 세션)과 PC RC 세션은 **서로 다른 세션**이다.
  클라우드 세션에서 PC 세션으로 직접 메시지를 보낼 수는 없다.
  폰에서 **PC 세션을 직접 골라** 명령하는 것이 맞는 사용법이다.

## 이 프로젝트에서 어디서 무엇을 하나

| 작업 | 실행 위치 |
|---|---|
| 인스타 게시 · 댓글 답글 | **PC RC 세션** (로그인된 브라우저 필요) |
| 원본 영상 분석 · 편집 · 렌더 | **PC RC 세션** (원본 파일·ffmpeg 필요) |
| NAS 최종본 업로드 | **PC RC 세션** |
| 스토리 이미지 생성 (사진만 있으면 됨) | 어디서든 |
| 문서 · 기획 · 문안 작성 · 계정 분석 | 어디서든 |
| 스토리 @멘션 · 링크 스티커 | **폰 인스타 앱** (앱 전용 기능) |
